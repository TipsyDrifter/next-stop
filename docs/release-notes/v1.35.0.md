# v1.35.0 · 排程與記錄意圖大一統（期間自由券、預留席車票、定期班次填空＆待辦入座）、車站主畫面軌道條、三欄「行路企劃書」方針工作台與全站順手度大升級

這一版專注於消除日常記錄與排程的心智摩擦：不再為了「這件事該開哪種票、還不確定具體哪天做怎麼辦、固定週一預留 2 小時學習卻跟具體作業重疊要蓋兩次章」而猶豫——全新 **「期間自由券（如 `10/2~10/4`／本週／本月）」** 安靜收納於今日頁下方的可收合抽屜，建票列輸入 `@日文 2h` 免填標題即可建立雙邊互通的 **「預留席車票」**，定期預留班次更支援 **「本班填空」** 與 **「待辦入座頂替」** 雙模式（永遠一張乾淨車票、時數只算一次、蓋一次 `済` 同步結案）。同時將車站拉上路線主畫面 **「站點軌道條」**（支援支線／列車掛站繼承與拖放歸站），將寫方針升級為寬敞的 **三欄「行路企劃書」工作台**，並一次拉齊 `@路線`／`#荷札` 打字補完、起訖時刻 ⇄ 時長雙向互推、多選批量操作完全體、車票完成卡與點空白處收起等二十餘項全站體驗細節。桌機與手機同一版號。

## 主人會看到

### 排程與記錄意圖大一統：預留席車票、期間自由券 ＆ 定期班次填空／入座
- **建票列免填標題直出「預留席車票」＆ 今日頁 ⇄ 時刻表日程完全互通**：
  - 在建票列只要指定路線或荷札加上時長（如 `@日文 2h`、`#學習 14:00-16:00`），不必硬想具體標題、也不必先定幾點幾分，即可直接建立虛線邊框的「**預留席車票**」（事後填入具體名稱即自動轉正）。
  - 退役過去孤立在時刻表角落的「臨時班次」（舊有未刪紀錄於升級啟動時自動無損轉為預留席車票）；在時刻表日程軸空白處拖拉建立預留時，與今日頁讀寫同一張預留席車票，今日小結亦新增去重後的「**已排 Xh**」預估總時數。
- **「期間自由券（任意日期範圍 `10/2~10/4`）」與今日頁可收合抽屜**：
  - 月曆挑選器與推遲面板新增「**單日 ｜ 區間**」切換，可點選任意日期範圍（如 `10/2–10/4`）或一鍵套用 `週末`、`本週`、`下週`、`本月`（建票列直接打 `10/2~10/4` 或 `本週` 亦即時辨識）。
  - 凡區間涵蓋今日的未結案自由券，統一安靜收納於今日頁主清單下方的可收合「**期間自由券**」抽屜（未到起點不提早打擾、無項目時自動隱藏），依結束日由近到遠排序，支援在抽屜內直接蓋 `済`、按 `▶ 発車` 或一鍵「**排今天**」（拖上時刻表時間軸亦自動收斂為當日單日票並支援復原）；有效期間內絕不判為誤點，逾結束日未結案隔天起才進誤點區提醒重排。
- **定期預留升級「本班填空 ＋ 待辦入座頂替」雙模式**：
  - **用法 A · 本班填空**：對當期定期班次填入「本班內容」（如在每週一 `學習 · 2h` 寫入 `念線性代數 Ch.3`），票面與時刻表即顯示 `念線性代數 Ch.3（↻ 學習 · 2h）`，蓋一次 `済` 完整留存足跡，下週一自動恢復空白預留名。
  - **用法 B · 待辦入座頂替**：將路線圖既有的待辦車票（如『寫 OS 作業』）直接拖放或透過挑選器配對坐進某班定期預留或單次預留席——空殼預留席自動隱身，**畫面永遠只顯示一張車票、預計時數與日記／報告済章皆精準只算一次、蓋一次 `済` 即雙邊同步完成**（改期移走或按「釋出預留席」即自動還原空位）。

### 路線主畫面「站點軌道條」與三欄「行路企劃書」方針工作台
- **路線主畫面橫向「站點軌道條」＆ 支線／列車掛站繼承**：
  - 路線大綱與看板頁首下方新增橫向「**站點軌道條**」（手機支援順手橫滑）：一眼看清「已到站 ● → 下一站 ◎ → 未到站 ○」與每站底下涵蓋車票完成數（`済 d/t`＋進度微條），支援主畫面原地建站、單擊單站聚焦篩選、以及直接把項目拖到站點圓標上歸站。
  - 開放**支線、列車、車廂**直接設定所屬車站，子車票未單獨覆寫時自動沿母列車／母支線繼承歸站，徹底解決看板切「依車站」時支線與列車消失的問題；建票列、雙擊編輯與選單同步補齊選站入口。
- **寫方針升級寬幅「行路企劃書」三欄同屏對照工作台**：
  - 桌機點「改方針」展開 `1140px` 寬敞三欄書頁——左欄「今年」、中欄「本月」、右欄「本週」同屏並排獨立翻期對照與原地多行編輯（放寬至 160 字自動增高，支援 `Shift+Enter` 換行、`@路線` 補完與跨尺度一鍵引流），方針掛載簡化為依幹線分組一鍵秒選路線（手機為滿版舒適分頁）。

### 全站順手度、快速語法與多選批量完全體
- **標籤語法即時補完 ＆ 全站 13 處「起訖時刻 ⇄ 時長」雙向互推**：
  - 建票、改票與寫方針輸入 `@` 即彈出依幹線分組路線補完、輸入 `#` 彈出荷札補完；補齊 `=`／`〆=` 觸發「締切同乘車日」語法與 `14:00-15:30` 起訖自動拆算時長語法。
  - 全站 13 處時間與時長欄位全面接通「改結束時刻自動反推時長 ⇄ 選雙排時長自動正推結束時刻」雙向連動。
- **多選批量操作完全體**：雙端選取列補齊批量改締切（含同乘車日）、開始／結束時刻、預計時長、推進狀態與結案印記、車站、定期規則與取消運休；收件匣與候車室同步補齊多選整理列。
- **車票完成卡對齊、階層搬移去重 ＆ 點空白處自然收起**：
  - 車票蓋 `済` 與列車／車廂一致彈出完成卡（選心情三色燈＋寫一行乘務記錄，`Esc` 跳過），車票詳情頁開放選心情與掛載旅客筆記、補齊上方「掛在」階層改掛欄（全站選路線依幹線分組，一般票收起重複區塊）；路線大綱建票列提供「車票｜支線」切換與雙向轉型。
  - 修復拖曳列車至支線與多選父子跨路線搬移時的子樹去重、以及路線篩選清單保留母列車縮排脈絡；點擊主畫面空白處即自然收起多選列與詳情側板（建票有字自動發券、改票失焦自動保存）。
