## v1.2.0 · 旅客筆記① 捕捉・收件匣・筆記

側欄最後一枚「旅客筆記」通車了。這一版先蓋好入口：想到什麼隨手記一句，不必先想好要放哪裡；記下來的東西要麼直接分流到該去的地方，要麼先進收件匣蓋個受付章，之後一個動作送走。桌機與手機同一版、功能對等。

### 主人會看到
- **旅客筆記頁**：桌機側欄下排的「旅客筆記」不再反灰，`Ctrl+4` 直達；手機底部第三格亮起。頁內分「收件匣」與「筆記」兩區。
- **隨手記一句**：
  - 桌機在任何一頁按 `Ctrl+N`（或側欄搜尋鈕旁的捕捉鈕），畫面中央浮出一張票形捕捉框，游標已就位。
  - 手機每個分頁右下角都有一顆圓形浮動鈕，點了從底部升起捕捉面板（手機上 `Enter` 是換行，按「存」存檔）。
  - 捕捉框下方一排票根可以分流：選「待辦」就直接排進今日；什麼都不選就進收件匣。開頭打「路線代碼＋冒號」（全形、半形，冒號後有沒有空格都認得）會自動掛到那條路線、直接留作筆記。
  - 存完會出一則提示，10 秒內可以「復原」。有內容時按 `Esc`／取消會先問一次，不會手滑丟掉。
- **收件匣**：裝兩種東西，都蓋受付章（印著收進來那天的日期）：
  - 還沒整理的筆記：可以「變待辦」「留作筆記」或刪除。
  - **沒有日期、沒掛進樹、也沒掛路線的臨時車票**：可以排今天、排明天、排某天、掛進列車、掛上路線或刪除。車票一旦有了日期、掛進樹或掛了路線，就離開收件匣。**這是收件匣定義的收窄**（D-筆-17）：以前「無日期的臨時車票＝收件匣」，現在掛了路線的不再算，它會出現在那條路線大綱的頂層。
  - 今日頁 `Shift+Enter` 建的無日期票、推遲小卡「清除執行日」的票都會來這裡；`Ctrl+P` 搜到它按 `Enter` 會直接跳到收件匣並選中。
  - 桌機鍵盤可以全程操作：↑↓ 選、`T` 變待辦／排今天、`Shift+T` 排明天、`N` 留作筆記、`L` 掛進列車、`R` 掛上路線、`Delete` 刪除。整理完畫面寫「沒有待整理的東西」。
- **筆記**：列表是舒適密度（標題、兩行摘要、日期與掛在哪），依月份分隔、新的在上；可以依路線篩選（含「無路線」）、搜尋。點一則看排好版的閱讀狀態，點一下或按 `Enter` 進編輯，`Esc` 或點外面回閱讀並自動存檔。標題可以不寫。可改日期、改「掛在哪」（路線，或往下選到支線／列車／車廂；也可以摘掉）。
- **筆記變待辦**：一行變一張車票；多行或條列會先跳預覽，每條各一張、可以勾掉，標題行預設不勾。預覽裡可以選「掛到哪」（路線，或往下選列車、車廂）與執行日，不選就是今天、掛筆記原本的路線。變完原筆記收起，可以復原。
- 刪除筆記一律可復原（10 秒內）。
- 「?」快捷鍵指引多了旅客筆記一段，全域段多了「記一句」。

### 底下換了什麼
- **並行地基**：側欄、全域浮層、快捷鍵、同步表都改成「登記式插槽」，各功能線在自己的登記檔填一行就接上，不再改共用的殼；migration 清單收成單一來源（版號、檔名、說明同一行，SQL 一律以 LF 進資料庫）。
- **新同步表 `notes`**：筆記會跟著既有的端對端加密同步在各台之間往返，欄位級合併（兩台同時改同一則內文，以後寫的為準）。
- **migration 0005**：新增 `notes` 表（日記用的欄位先預留）。升級時照舊先備份再升級；舊資料不動。

### 這一版的邊界
- 還沒有：荷札（`#` 目前只是文字）、日記與當天足跡、Markdown 排版（閱讀狀態只分段落與換行）、`Ctrl+P` 搜筆記、App 不在前景時的捕捉小窗、側欄的收件匣未整理數小牌。這些排在之後的版本。
- 兩台同時改同一則筆記的內文，較早那份不會留痕。
- 〈備份與還原〉危險區的確認文案還寫「清空所有車票與記錄」，沒提到筆記（筆記一樣會被清掉）；下一版補字。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝
- Android（arm64）：`NextStop_1.2.0_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.2.0_x64-setup.exe`（NSIS）。
