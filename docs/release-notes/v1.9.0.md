## v1.9.0 · 旅客筆記：筆記掛樹・Markdown

旅客筆記的第四站。筆記讀起來有排版了，也能從路線那一側直接看到、記下掛在上面的筆記；Ctrl+P 也搜得到筆記與日記。桌機與手機同一版。這一版**沒有新的資料庫 migration**。

### 主人會看到
- **筆記與日記讀的時候有排版**：`# 標題`、條列（可以巢狀、可以有序）、`**粗體**`、`*強調*`（中文畫成字下加點的著重號）、行內程式碼與程式碼區塊、引用、分隔線、連結都會排好；字放大到 16px、行距收一點，長文比較好讀。寫的時候還是純文字，點一下或 Enter 進編輯、Esc 回來。
- **連結點了開瀏覽器**：`https://…` 或 `[文字](https://…)` 會畫成連結，點了用系統瀏覽器打開，不會誤進編輯。
- **點開一班列車就看到它的筆記**：路線、支線、列車、車廂的側板多一列「筆記」。直接掛在這裡的排前面，掛在底下的接在後面、標「› 車廂名」；最多五則，多的點「還有 N 則 → 到旅客筆記看」。手機在路線圖的詳情與路線抬頭下也有。
- **在這裡記一則**：側板的「＋ 在這裡記一則」叫出捕捉框，已經選好「筆記」、掛好這個節點，記完留在原頁。
- **Ctrl+P 找得到筆記與日記**：路線與車票的結果後面多「筆記」「日記」兩組。
- **刪路線時提醒掛著的筆記**：確認框多一句「有 N 則筆記掛在這裡」——筆記不會跟著刪，之後顯示「原節點已刪除」，可以再掛到別處。
- **日曆的當天清單有日記入口**：行程表月檢視點一天，底部有「N 篇日記 ›」或「寫這天的日記 ›」，補記可以從這裡起手；寫完日記，格子上的記號馬上出現。
- **兩台同時改同一則時不再留下多餘的荷札**：另一台的修改比較新時，離開編輯後畫面會換成那一份，荷札也照那一份對齊。存檔失敗時一律保留你打的字。

### 底下換了什麼
- Markdown 是自己寫的小解析器（不加套件），和荷札用同一套規則判斷 `#`——讀的時候畫成小牌的，就是實際掛上的那些。
- 路線、日曆、刪除確認框多了讓各條線掛東西的位置（地基小修，別條線之後也能用）。
- 側板與 Ctrl+P 用到幾支新的查詢；資料表沒有變。

### 這一版的邊界
- 在捕捉框或筆記裡打完 `#荷札` 按 Enter，第一下會被荷札建議接走（選了「建立」），要按第二下才存檔或換行；Esc 也是先收建議。這是荷札那一版就有的行為。
- 手機捕捉框存檔失敗時，提示會被重新彈起的鍵盤蓋住，收起鍵盤才看得到；之後修。
- 裸貼的網址後面緊接中文時（例如 `https://a.com的說明`），後面的中文會被算進網址；中間空一格就好。
- 不做：表格、圖片、可勾選的核取框（`- [ ]` 只是文字）；Ctrl+P 不搜工作日誌的內文。
- 還沒有：App 不在前面時一鍵記一句的小窗（旅客筆記⑤）。
- 仍需自己的 Cloudflare R2（自用階段）。
