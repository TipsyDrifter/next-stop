# v1.25.0 · 截止提醒、最近刪除、自訂快捷鍵、點選時間；重複任務補完、月年與車站方針

第五本第二梯的八項合在一版：截止前會提醒；刪掉的東西 30 天內撿得回來、資料可以匯出；快捷鍵可以自己改；選時間改成點錶盤；時刻表正在跑的那一班變乾淨；一批「小鈕太散、每次多點一步」的地方一起收攏；定期券能設結束、能只動其中一班；方針不只寫週，月、年、車站也能寫。桌機與手機同一版。**這一版沒有資料庫升級，不升級的那台照樣能同步、不會壞**；不過定期券的新設定、月與年與車站的方針，舊版那台看不到，建議兩台一起升級。

## 主人會看到

### 截止提醒：一頁收齊全 App 的提醒
- **車票截止前會提醒**：前一天晚上（預設 21:00）、當天早上（11:30）各一則，點開直接到那張票。同一天好幾張併成一則，點開到行程表那天；車站的預定到站日也算。
- **誤點滿 3 天提醒一次**；**排了時刻的票**開始前 10 分鐘也會響（定期券每一班、多時段每一段都算）。
- **週方針的週末回顧、定期帳當天、作息時段**也能提醒，後兩種預設關著（帳本會自己記、作息一天好幾段）。
- **所有提醒集中在一頁**：桌機在設定的〈提醒〉（第二籤），手機在「更多 › 提醒」。原本的「跑太久」提醒搬到這頁，同步警告多一個開關，**備份連續失敗現在也會通知**。頁底有「最近的提醒」近 30 則，點了直達。
- 開關和時刻**各台自己記、不同步**（常見的是手機開、電腦關）；兩台都開就兩台都響。
- 手機 App 沒開也會響；電腦要開著（縮在系統匣也行），開 App 時會補當天漏掉的。
- 不催人：「你還沒做到」型的提醒（時數目標剩幾天、預算超支、每晚寫日記、週一還沒寫方針）沒有做；願望清單沒有日期，所以也沒有提醒。

### 失物招領：刪掉的東西撿得回來，資料也能帶走
- **最近刪除**：桌機設定最右一籤，手機在「更多」的「備份與還原」上面一列。30 天內刪掉的車票、筆記、日記、荷札、時間塊、目標、作息範本、帳目、定期帳、願望、常用票種、預算、方針，依刪除日期列出，可搜尋、可用分類篩，每一列一顆「撿回」。
- 原本的上層不在了：車票會先放進臨時車票；其他種類會問你要不要連它的上層一起撿。荷札撿回時，被摘掉的筆記會把 `#荷札` 補在最後一行。定期帳撿回，刪掉期間的班次不補。
- **從雲端備份撿回單筆**：備份清單每一份多「撿回單筆…」；筆記、日記、車票被改壞了，也能並排看備份當時與現在、按「改回」。
- **匯出資料**：在〈備份與還原〉，整份或單一模組（任務、筆記、時刻表、售票口），JSON 或 CSV（CSV 是一個 zip、每種資料一張表）。手機存到你在系統存檔畫面選的位置。
- **更多地方可以復原**：預算、方針刪句、作息換套與「這天不套」、清掉逐班時刻、時間塊合併。
- **刪除的行為統一**：子項數量全 App 用同一個算法，刪除失敗不會再跳「已刪除」，收件匣的票有 5 個以上子項也會先問；提示文字統一成「已刪除「名稱」」。

### 快捷鍵可以自己改
- 設定的〈快捷鍵〉：**點鍵帽，按下新的組合鍵就換好**，Esc 取消。撞到別的功能時照樣存，兩列的鍵帽標赭色、籤頂寫撞了幾列；每列有「還原」，也有「全部還原預設」（可以復原）。
- `?` 卡、選單右邊的字、按鈕的提示都會跟著新的鍵變，不用重開。
- **背景記一句的 `Ctrl+Alt+N` 也能換**：跟別的軟體衝到時不用再關掉對方。換的鍵被別的程式佔走時會退回原本的並說原因，〈一般〉那句會指到〈快捷鍵〉。
- **多選有「全選」按鈕了**：桌機在選取列，手機在選取列「更多」的第一項；串流的 ⋯ 也能「選取」。
- **手機「更多」多一頁「手勢與長按」**，手機上有哪些手勢一次看完；手機上的提示不會再叫你「按 U」。
- 改過的鍵只存在這台，不同步。Esc、輸入框裡的 Enter／Tab／↑↓、日記存檔鍵不開放改（它們是輸入習慣，不是偏好）；手機的手勢不能自訂。

### 選時間不用再打數字
- **點時刻框就開選擇器**：一面站鐘錶盤，外圈 1–12 點、內圈 13–00 點，點了小時自動換分鐘；分鐘點一下落到 5 分一格，拖動可以準到 1 分（落到隔天的小時是赭字），還有「現在」；打字和 ±步進都留著。桌機是框旁的浮層、挑了馬上生效、Esc 還原；手機是底部面板、按「完成」才生效，取消或返回不動原值。
- 設定的「一天的開始時間」改成分段鈕，不再是原生下拉。
- **標題和按鈕不再跳**：售票口、時刻表、行程表切分頁時，標題、分頁籤和新增鈕的位置不動。不同模組之間（例如今日到行程表）頁首寬度不統一，只管同一個模組內。

### 時刻表：正在跑的那一班變乾淨
- **運行列**：點它左半邊整塊就能「改這一班」（連到、荷札、備註、切開、預估都在裡面），上面只留換車和到着；面上只有淡淡的狀態字（預估、誤點、長時間運行）。
- **待確認時**多一條赭色窄條，一點直接問你「其實到幾點」；**這個問題會記住你上次選的**。
- **発車與換車的出發時間可以直接填或點選**（原本的 5／10／20 分鐘前拿掉了），預估也能自己填分鐘數，発車面板的「＋預估」記得展開與否；発車後 toast 的「改 10 分前」換成「改時間」。

### 一排散落的小鈕收進 ⋯、常用的選擇記住上次
- **清單變清爽**：分類、常用票種、作息範本、目標的上移／下移收進 ⋯（也可以直接拖，名稱框裡 `Alt+↑↓` 照舊）。
- **多選工具列**：桌機和手機一樣，常用的三顆（蓋済、執行日、移動到…）在外面，其他在「更多」。
- **收件匣的臨時車票**：只留排今天、排明天、挑日期三顆，其他（掛進列車、掛上路線、荷札、刪除）在「更多」；桌機滑鼠滑過不會再一直選中、把下面的列推開，點一下或按 ↑↓ 才選。
- **手機刪車站**改在左邊的抓手裡，蓋章時不會再誤按。
- **記住上次**：售票口停在哪個分頁、統計看月或年、哪個切面、收入或支出（以前每次都回清單）；轉帳會幫你填上次轉進的帳戶；手機今日的誤點區、日記的足跡區收起來也會記住。這些都只記在這台、不同步。

### 重複任務補完
- **定期券能設結束**：到某天為止，或做滿幾次（只數蓋了済的，運休和漏掉的不算）；做滿就自動到站。
- **每 N 天、每 N 週、每 N 個月**都能設（例如每 2 週、每 3 天、每 3 個月）；週以週一開頭。
- **只動這一班**：拖到別天，或在小卡裡改「本班日期」，其他班不受影響。改重複規則不再清掉今天那班的時刻，只有換了排程才清未來的覆寫。
- **有子項的列車也能重複**：蓋完這一班，底下的項目自動回到未完成、下一班重來，這次的完成紀錄都留著；最後一班不重置。
- **定期帳**可以記滿幾筆、每 N 期、提前跳過下一班（還沒到的跳過會留一行「已跳過…復原」）。
- 入口：車票側板與手機詳情的重複段（多「間隔」「結束」兩列）、票卡 ⋯ 的「這一班改到…」、行程表直接拖；售票口定期帳的表單與管理頁。外部助理的「改期」帶別天，也是只動那一班。

### 方針擴充：月、年、車站也能寫方針
- **月、年的方針**：今日告示最下面多一行露出本月與今年（有寫就顯示句子，沒寫是「＋ 寫本月方針」），點了就切過去；行程表月視圖頂端是那個月的方針，車庫年鑑頂端是今年的（頭上可翻年）；時段檢視頂端的週告示固定收合、可展開。手機今日那一行底下多兩行，面板上方分頁「本週｜本月｜今年｜下一站」。
- **車站方針與車站小卡**：點車站（車站清單每列、路線頁與今日頁首的「下一站」紀念章、路線一覽卡的下一站、行程表月視圖的 ◎、手機路線詳情與路線圖）會開一張小卡：站名、預定日與還有幾天、這一站的每句方針（可蓋済、排成車票）、「帶到下一站」「回顧」「改方針」「蓋到站章」。路線頁在下一站有方針時多一行「下一站方針」；行程表月視圖有預定日、還沒到站的車站，在日期旁標一個 ◎。
- **到站與回顧**：蓋到站章時，那一站有方針會提示「回顧」；新的一期打開時，上一期的回顧照週→月→年一次一張出現；回顧頁腳「帶到下週／下個月／明年／下一站」。記錄簿「經過的車站」每站底下列當時的方針。
- 寫方針框會列出上一層的句子（寫週看本月、寫月看今年），一句一顆「帶進來」。
- **外部助理**（只在桌機）多三支方針工具（看、新增或修改、蓋済），走任務的開關；**完整搜尋**也找得到方針句子，點了到那一期。
- 不做的：串流不放方針；沒有連續期數、達成率；回顧不能「寫成日記」；不做樹狀拆解。

### 修正
- **手機點提醒不再落錯**：App 被系統收掉之後，再點提醒、點常駐的時刻表通知、點「跑太久」提醒，現在都會正確落到那一張票（或問「其實到幾點」）；以前會停在今日，或從最近任務回來又重跳一次舊的那張。
- **行程表月、週格裡的票終於拖得動了**；多選後可以整批拖；路線圖的進度圈點得到了。
- **寫方針框開著的時候另一台同步進來**：存檔不再讓別處刪掉的句子復活，也不會刪掉另一台剛寫的句子。

## 底下換了什麼
- 這一版 **0 個 migration**；〈提醒〉的開關與時刻、自訂快捷鍵、各種「記住上次」都存在這台、不進同步。
- 定期券規則多了 `moves`、`interval`、`count` 三格，方針表的 `week_on` 放寬成「期間鍵」（週、月、年、車站），都不動資料庫結構；沒升級的那台收到會照樣收，只是看不懂新格子。
- 桌機提醒由 Rust 直接送 Windows 通知；Android 加了原生的鬧鐘層（Kotlin），點通知先到一個不留在任務裡的中繼頁再開 App。全域快捷鍵、匯出、雲端備份撿回單筆各多了 Rust 指令。

## 這一版的邊界
- **電腦點通知回到票，只在通知還在螢幕上時行**（通知停留約 25 秒）；消失後從 Windows 通知中心點，點不回 App——這時從〈提醒〉頁底的「最近的提醒」進去。想讓通知中心也點得回來要另外裝一個接口，等你用過再決定。
- **手機各項在模擬器上走過，還沒在你的手機上親手點完**：提醒（準時鬧鐘、重開機後照響、鎖屏只顯示「有新的提醒」、關掉再打開通知權限）、最近刪除與匯出、車站小卡與月曆的 ◎、定期券的長按拖曳。請上機後先看這幾處。
- 手機排程是 App 上次開著時算的：另一台做完了、這台沒開 App，可能響一則已經做完的，點開會看到「済」；超過兩週沒開 App 就排不到新的。
- 提醒：電腦安裝版上通知的圖示與名稱、縮在系統匣時點通知能不能把視窗拉到前面，還沒親眼確認；Android 一組 3 則以上提醒收合時，點那一行沒有目標（會落到今日）。
- 沒有永久刪除鈕（同步需要留著刪除記錄，真的刪不掉；30 天只是清單顯示的範圍）；匯出的檔案 App 不能再匯入。手機匯出存到雲端硬碟這類關檔後才上傳的位置，寫入失敗時會不會誤報成功，還沒驗；整份大快照在手機上的記憶體與耗時、電腦原生存檔對話框存到中文路徑，也還沒親手點過。
- 一台刪掉又撿回、另一台剛好同時也刪了同一筆：同步後兩台會各留各的（一台在、一台不在）；到刪掉的那台再從「最近刪除」撿一次就拉齊。另一台正開著編輯框時收到「改回」，下一個打的字會把改回的內容蓋掉，沒有提示；刪荷札留下的空行，反覆刪、撿回會累積。
- 快捷鍵：**實際按新的全域鍵叫出小窗這一步沒有親手按過**（換鍵、放鍵、被佔走退回、重開記得、全部還原都驗過）；`Ctrl+.` 在時刻表、售票口、旅客筆記按下去畫面沒反應，先記著。
- 時間選擇器：各處的時刻框沒有逐一點開看過（窄欄擺不擺得下）；日程的計畫面板與時段面板開著選擇器時按 Esc 會關整個面板，別處只關選擇器；售票口詳情側板還開著時再點帳目，頁首一度被擠窄（切分頁就回來）；視窗窄於 1180 時右邊會被切（原本就如此）。
- 時刻表：「繼續跑」和「就是這麼久」共用一個記憶值，選過「繼續跑」後，確認已結束的塊也會預選「就是這麼久」；運行列上不再畫「切開」的 `S` 鍵帽（鍵本身照舊，`?` 說明頁看得到）；補記面板的分類格在 860 高的視窗仍要捲一小段。
- 收攏後：售票口〈帳戶順序〉那頁每一列還有自己的 ↑↓，這版沒收；售票口的視圖只在 App 剛開時套回，開著時把視窗拉窄變成手機版面不會跳到手機版上次的分頁，轉帳記憶一台一份。
- 重複任務：兩台同時改同一張票不同班的日期，其中一邊會被蓋掉；子項自己有今天的執行日時，蓋完上層會從今日清單移走（已平移到下一班），完成記錄仍在足跡裡；手機路線圖這一班已經交代過時，「本班日期…」會淡掉；單一班次不能改名、改內容，作息範本還沒有「結束日」。
- 方針：手機今日那一行的上層兩行為了按鈕有 44px，比原型高約 27px，要貼回原型就得把按鈕做小；月底「回顧這個月」、12/31 年回顧只用日期判斷測過，沒真的走到那一天；既有的週方針升級後是否照舊，驗證時用的是空資料庫，裝上後看一眼；月視圖同一天有車站 ◎ 與截止 〆 時兩個記號會重疊。
- 仍需自己的 Cloudflare R2（自用階段）。

## 安裝
- 桌機：`NextStop_1.25.0_x64-setup.exe` 直接升級安裝。
- 手機：`NextStop_1.25.0_arm64.apk` 覆蓋安裝（同簽章）。
