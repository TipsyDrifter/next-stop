# v1.34.0 · 旗艦時光手繪主題「水鏡鎌倉・湖上列車」、亮暗主題自由配對與依時切換、時刻表 16 色＋自訂色碼 ＆「霞鶩文楷 TC」字型

這一版聚焦於日常陪伴的風景與筆觸美感：全新旗艦時光動態主題 **「水鏡鎌倉・湖上列車」** 登場，以 16:9 原生 4K 超採樣四時手繪畫卷呈現朝霧、晴空、暮色、星夜的絲絨雲霞與靜謐水鏡，對岸山腳微縮電車帶著暖金燈窗與倒影緩緩滑過，並支援清透的微雨山嵐、斜雨絲與湖面雨滴漣漪；主題系統全面開放 **自由配對「我的亮色／暗色代表主題」** 與 **依時間自動切換日夜**；時刻表分類擴充至 **16 款鋼筆墨水色票＋`#RRGGBB` 自訂色碼**，主題商店字型架亦新增日文假名齊全的 **「霞鶩文楷 TC」**。桌機與手機同一版號。

## 主人會看到

### 旗艦時光手繪動態主題：「水鏡鎌倉・湖上列車」
- **四時流轉的手繪水鏡畫卷**：
  - 到設定〈一般〉（手機〔更多 › 設定〕）的「主題商店」即可免費領取套用「**水鏡鎌倉**」。
  - 全場景由 4K 超採樣手繪畫作層疊合成：近景為逆光石板步道、五木樁老杉木欄杆與兩側曲折冬枝，中景為絲絨般微晃的開闊湖面水鏡，遠景為海灣山巒與入夜後柔和呼吸的萬家燈火。
  - 天色與前景光影隨一天 24 小時連續流轉：**朝霧柔金 → 白晝湛藍 → 黃昏玫瑰紫霞 → 星夜群青彎月**；也可在設定中手動鎖定最喜歡的單一時段。
- **對岸山腳微縮列車、蓋章發車儀式 ＆ 清透微雨山嵐**：
  - 對岸山腳水際線上，復古雙節路面電車會不定期緩緩駛過並在水面映出微光倒影；當你在今日頁蓋下「済」章時，還會觸發列車發車或白鷺掠過遠空的溫柔小儀式（今日全數蓋完時更會開出三節特快編成）。
  - 天象支援「**自然天象 ｜ 晴朗 ｜ 微雨山嵐**」切換：微雨時遠山山腳浮起薄薄水彩山嵐、落下細緻斜雨絲，湖面泛起透視雨滴漣漪，同時保持水鏡與前景深邃通透。
  - **省電與閱讀守門**：全時段手帳紙卡與文字皆通過對比度守門；視窗縮小、切到背景或開啟系統減少動態時自動降至 `0fps` 靜態畫作，夜間與手機端亦自動關閉多層毛玻璃模糊以維持冰涼省電。

### 主題自由配對 ＆ 四模式日夜切換
- **自由指定「我的亮色主題」與「我的暗色主題」**：
  - 不再綁定預設組合——可從粉彩星空、銀河鐵道、旅の手帖、少女手帳、夜行寝台、月白、水鏡鎌倉中，任選一套當白晝代表、一套當入夜代表（例如白天用「旅の手帖」、晚上自動切「夜行寝台」或「水鏡鎌倉・星夜」）。工具列的日夜切換鈕也會照你的配對一鍵往返。
- **四種主題運作模式**：
  - 提供 **`手動固定 ｜ 跟隨系統 ｜ 依時間切換（預設 06:30 亮／18:30 暗，可自訂時刻並支援跨午夜） ｜ 水鏡鎌倉全天候`** 四種模式，開頁瞬間即套用對應天色、不閃白畫面。

### 時刻表 16 色鋼筆墨水色票、`#RRGGBB` 自訂色 ＆「霞鶩文楷 TC」字型
- **時刻表分類擴充至 16 色 ＋ 任意 `#RRGGBB` 自訂色碼**：
  - 分類色盤由 8 色擴充為 16 款沉穩的文具鋼筆墨水色票，並支援直接輸入 `#RRGGBB` 自訂專屬色碼。
  - 自訂色內建亮暗雙底自動對比度調適（無論挑極深或極淺色，在亮色與深色主題的時間軸、方眼、統計、通知與桌面小窗上皆清晰好讀），並完整支援跨裝置加密同步。
- **主題商店新增手寫楷書字型「霞鶩文楷 TC」**：
  - 字型架新增開源手寫楷體「**霞鶩文楷 TC**」（按需下載、本機快取並附雜湊校驗），完整收錄繁體中文與日文平假名、片假名及鐵道手帳常用的 `〆`、`・` 等符號，不再缺字跳回預設黑體。
