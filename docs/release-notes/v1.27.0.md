# v1.27.0 · 既有車票雙擊行內編輯、締切同步乘車日、手帳紙卡下拉選單、管理列動作浮現、記住最後分頁與介面細節打磨

這一版專注於日常操作的順手度與畫面細節打磨：雙擊既有車票就能直接在行內展開細項膠囊列（不用再為了改日期或荷札特別打開右側詳情板）；「執行日」全站統一改稱更具鐵道溫度的「**乘車日**」，並支援一鍵將締切設為「**＝同乘車日**」；全站 17 處瀏覽器原生白底淡字下拉選單全面換成手帳紙卡浮層；分類管理列與常用篩選列的「改名、設定、封存、刪除」直接浮現在列尾，單擊與拖曳不再誤觸打字框；離開 App 前的最後分頁與子視圖也會自動記住。桌機與手機同一版，無資料庫遷移。

## 主人會看到

### 既有車票雙擊行內編輯 ＋ 締切「＝同乘車日」一鍵同步
- **雙擊車票原地展開完整編輯器**：在大綱、今日與行程表當日清單雙擊任一張既有車票，除了改標題（支援 `!高 #荷札 14:00` 語法），底下會直接展開跟建票列同款的細項膠囊列（乘車日、時間、締切、優先級、`#荷札`）。
- **表層徽章單點快改**：不進編輯態時，直接點車票列右側已顯示的日期、優先級或荷札徽章，也會直接彈出對應挑選器秒改。
- **締切「＝同乘車日」同步**：建票列、行內編輯與詳情面板新增「**＝同乘車日**」一鍵同步鈕；當締切與乘車日對齊或開啟同步時，調整乘車日會自動跟著推進締切日，不用再開兩次日曆。
- **「執行日」統一改稱「乘車日」**：全站建票膠囊、詳情欄位、篩選條件、匯出報表與提示文案全面統一為「乘車日」（快捷鍵與語法維持相容）。

### 分類管理列動作浮現、防誤觸改名與批量拖曳
- **管理列常用動作直接浮現**：分類管理窗（幹線、時刻表分類、售票口分類、帳戶、候車室番線、荷札）的「**改名、更多設定、封存、刪除**」，以及路線看板常用篩選列的「**帶入、改名、刪除**」全部直接浮現在列尾表面，不用再多點一層 `⋯`。
- **單擊與拖曳不再誤觸打字**：管理列的名稱欄預設為唯讀，按住整列上下拖曳排序時不會再誤觸游標進入打字；**雙擊列或點「改名」圖示**才會進入文字編輯。
- **拖曳零反白 ＋ 多選批量拖曳**：全站啟動拖曳時自動鎖定文字選取並清除殘留反白；在今日頁與行程表月曆格多選多張車票後，拖曳其中一張即可整批改期或排入指定日期。
- **建票與草稿快捷鍵統一**：全站新增列與草稿框統一為 **`Enter` 建立並完成退出**、**`Ctrl+Enter`（Mac 為 `Cmd+Enter`）建立並繼續輸入下一筆**。

### 手帳紙卡下拉選單、記住最後分頁與畫面細節修繕
- **消滅原生白底淡字選單**：新增自訂手帳紙卡 `<Select>` 浮層元件，將時刻表、售票口、設定、統計、匯入與搜尋列共 17 處瀏覽器原生 `<select>` 全面替換，文字採用清晰的濃墨色（`--color-ink`），支援鍵盤上下導覽與分組標題。
- **記住離開前的最後位置**：自動記住離開 App 前所在的最後主分頁、子分頁與選取的路線／筆記／車庫／候車室狀態，手機從背景切回或重開 App 時直接回到上次停留的地方（若原項目已刪除則安全退回今日頁）。
- **旅客筆記／日記編輯態左側邊線修復**：移除原本因負擴散外陰影被邊界裁切、緊貼字首且上下截斷的邊線，改以外層獨立圓角柔和細線繪製，與內文之間留出舒適的 14px（手機 8px）呼吸留白，讀寫切換維持 0px 零跳動。
- **畫面與體檢小接縫修繕**：
  - 消除粉彩星空與淺色主題視窗最頂部的 1px 亮白邊線。
  - 固定側欄收合／展開時頁首 `PageHeader` 的最小高度，切換側欄時標題不再上下跳動。
  - 切換至「今日」或「行程表」等非路線圖頁時，側欄書封自動清除原路線的金色菱形高亮與右縮。
  - 路線一覽與路線內頁頁首補齊右上角營業日日付印 `DateSeal`。
  - 修正行程表月曆格同一天有車站 `◎` 與締切 `〆` 時在格頂中間重疊的問題（改為 `◎` 靠左、`〆` 靠右分列）。
  - 修正時刻表日程面板開啟站鐘錶盤挑選時間時，按 `Esc` 會連外層日程面板一起關掉的問題。
  - 限制 `Ctrl+.` 僅在路線圖與行程表等有詳情側板的頁面觸發，避免在其他頁面誤翻動背景狀態。
