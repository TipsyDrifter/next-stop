## v1.17.3 · 磨光⑥：補記選時間、售票口排序（試用回饋）

正式啟用第一天的兩條回饋：時刻表補記不用再按 ±5 幾十下，售票口的帳戶和清單可以照自己的習慣排。這一版**沒有新的資料庫 migration**，也沒有改 Rust 側；兩台可以分開升級。

## 磨光⑥ · 時刻表可以直接打時間、售票口可以排順序

### 主人會看到

**時刻表**

- **時間可以直接打**：補記、改一塊、「其實到幾點」、改出發時間、切開，這五個地方的時間都能點下去直接打——`0830`、`8:30`、`2330` 都認得，`25:00` 也行（＝隔天 01:00，跟著日界線走）。打錯會抖一下、還原，下面一行告訴你哪裡錯。
- **微調鈕變多檔**：兩側是 −1h −15 −5 −1／+1 +5 +15 +1h，手機排成左右兩塊。按住不放會越跳越快。
- **一段空白可以連著補**：從軸上點一段未記錄補一塊，補完面板不關，直接停在剩下那段，接著補下一件事；整段補滿才關。不想補了按「先這樣」。
- 補記那段一路到現在時，到着旁的快捷改叫「接到現在」。

**售票口**

- **帳戶可以排順序**：電腦在側欄的設定選單、手機在管理頁，多了「帳戶順序」，同一個群組裡用 ↑↓ 排，兩台會同步。（分類的順序原本就能在「分類管理」裡排。）
- **記一筆的「常用」**：分類最上面那排改成最近 30 天最常用的；帳戶清單最上面多一排常用的三個，下面照你排的順序。
- **帳目可以換排序**：搜尋時多一個「排序」——日期新到舊／舊到新、金額大到小／小到大。一般清單的頁首也有排序鈕，選金額排序會直接列出這個月。依金額排時不分日、每筆標日期；關掉搜尋就回到依日期。

### 修掉的小毛病

- 父分類已經不在的子分類，在分類管理裡按 ↑↓ 沒反應。
- 補記過去某天最後一段空白（例如昨天下午到日界線）時，到着打下午的時刻會被誤擋；現在 1415、1745、0130 都接受。
- 打完時間按 Enter 跳到下一格後，內容會整個選起來，直接接著打就能覆蓋。

### 已知限制與請你用到時留意

這兩條只有真手機、真手指才看得出來，桌機代驗和沙盒都驗不到。用到時順手看一眼，有狀況記回饋筆記：

- **手指在時間欄附近捲動**，頁面要正常捲，不會誤點到時間欄或微調鈕。
- **軟鍵盤跳出來時**，輸入框不會被蓋住（點時間欄打字、點切點框打字都看一下）。

另外：手機這顆的完整動線（長按加速、八顆鈕排成左右兩塊、售票口常用列）沒有在真機上逐項驗過。
