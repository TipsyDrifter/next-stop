## v1.6.0 · 主線① 行程表

今日頁專心看今天；多日的事交給新的「行程表」——從今天往上下都能捲的日串流，加上原本的週、月視圖。桌機的「日曆」頁改名「行程表」並多一種「串流」排列；手機在今日 tab 裡多了「今日｜行程表」兩段，手機第一次看得到今天以外的日子、也能把票排到任何一天。桌機與手機同一版、功能對等。這一版沒有新的資料庫 migration，升級不動舊資料。

### 主人會看到
- **桌機・行程表**：側欄第三格改叫「行程表」（仍是 `Ctrl+3`）。頁首切換變三格「月｜週｜串流」。串流排列＝今天在頂端，往下是接下來的日子、往上是過去；票就標在它的日期上，誤點票在它原定那天（赭色）。今日段上方一行「◆ 誤點 N 件」，點了捲到最早的誤點日。連續沒票的日子收成一行「M/D – M/D 無班次」，點了攤開、再點收回；最早與最晚的票之外各一行「M/D 以前／以後 — 無班次」。
- **在任何一天建票**：點某天的日期列（或選中它按 `Enter`），底下出草稿列，打字 `Enter` 就是那天的臨時券；過去的日子不開票。
- **在任何一天操作票**：蓋済、運休、推遲都跟今日頁同一套。未來的票推遲小卡改寫成「往後推一天／下週一／選日期…／清除執行日」，「選日期」挑不到今天以前。定期券的未來班次可以提前運休；歷史班次唯讀。
- **串流的鍵盤**：`↑`／`↓` 走訪、`Space` 済、`T`／`Shift+T`、`U` 運休、`.` 開側板、`Home` 回今天、`Esc`；按「?」指引會顯示這張表。
- **記得你停在哪**：頁首切換會記住（關掉重開直接落在串流、今天在頂端）。
- **手機・今日 tab 兩段**：頂帶下方「今日｜行程表」，點或左右滑切換。今日頁跟以前一樣（誤點區展開）；行程表頁＝週條（七天可滑換週、今天靛色菱形、路線色點與〆）＋串流＋點月份開月曆覆蓋層（開著時週條收起）。頂帶標題跟著換成「行程表」，日付印留著。
- **手機 ⋯ 補齊**：今日頁與行程表每張票的「⋯」都有四項（推遲到明天／下週一／選日期…／清除執行日），定期券＝本班運休／取消運休。以前手機只能「推遲到明天」。
- **往上拉看過去**：過去的日子一段段補進來，畫面不跳；未交代的就是誤點、照樣可以蓋済或推遲，已交代的唯讀。
- **這次一起改的**：
  - 今日頁全済的那句話改成「明天要跑的，可以到行程表先排好」。
  - 設定頁「每週從星期幾開始」的說明改寫「行程表與旅客筆記的月曆都照這個排」。
- **兩台一起**：一台改票，另一台的行程表自動更新（手機也會，不用回前景或切頁）。

### 底下換了什麼
- **沒有新表、沒有新欄位、沒有 migration**：串流讀的是日曆同一份查詢（`listCalendar`）；只加一支唯讀的 `scheduleBounds()` 找最早與最晚的日子。
- **純前端**：新模組在 `src/ui/schedule/`（段落模型是純函式、有 27 項單元測試；視窗載入與捲動補償在 `useStream`）；手機新頁 `MobileSchedule`、兩段切換、週條、月曆覆蓋層；桌機 `StreamView`。
- **只改顯示文字**：頁面 id 仍是 `calendar`、快捷鍵 scope、設定鍵 `calendar_view` 都不動（它多收一個值 `stream`）。改名動到快捷鍵登記表的金樣，已重產。
- **同步後重載**：手機的同步套用後多重載日曆切片（接縫 #54，之後會收成登記式插槽）。
- 推遲小卡的共用日期挑選器加了下限＝今天。

### 這一版的邊界
- 還沒有：**車票的預定時刻**與週視圖展開成「時段行程」（下一班車次②）；桌機串流頁首沒有週條（用 ‹ › 一次七天與月份跳轉代替）；行程表沒有拖曳改日期。
- 手機行程表子頁裡，旅客筆記的「記一句」浮動鈕比今日頁高一截（59px，接縫 #53，旅客筆記線會修）；不影響操作。
- 票很少、最早的票在好幾個月前時，往上補載到一定程度會停一次，要再捲一下才繼續；整條內容比畫面矮時「以前」邊界不會出現（頂端那行收合區間可以點開）。
- 「每日」定期券在串流裡每天都有一列，所以有每日定期券時幾乎不會看到「無班次」的區間——與日曆同一條規則，是設計。
- 行程表上方「誤點 N 件」只算還沒交代的；今日頁的誤點區會把今天剛蓋済的留在原位，所以兩頁的數字可以不同。
- Android：第一次點日期列開草稿時，軟鍵盤可能把輸入框與「発券」鈕遮住、不會自動捲上來（往上滑一下就看得到；第二次起正常）。下一階段修。
- Android：「往上甩的同時補載過去的日子」這個情境只在桌機的真 WebView2 驗過不跳；手機上因為開頁時就會先把過去補到最早的一天，實際很難碰到，沒在真機複核。
- Android：在行程表子頁按返回鍵會直接離開 App，不會先回「今日」子頁——這是整個 App 的既有行為（時刻表的面板也一樣），返回鍵怎麼接是跨線題，之後一起處理。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝

- Windows x64：`NextStop_1.6.0_x64-setup.exe`（NSIS）。
