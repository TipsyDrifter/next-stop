# v1.39.0 · 跨模組輕量相片附件櫃、時間塊地點與一日生活掠影、時刻表行為鏈與系統訊息手帳化

這一版替記帳與時刻表補上了「拍下生活片刻」與「一鍵連貫節奏」兩塊拼圖：推出按需載入、零清單負擔的跨模組輕量相片附件櫃，讓售票口票根與時刻表活動照能隨手存檔、加密同步並在單日跨頁自然呈現為「當日生活掠影」；時刻表時間塊新增支援常用記憶的「地點」欄，並推出一鍵啟動、一路點「下一站 ›」無縫換車的「行為鏈（計時模板）」；最後將底層備份、雲端同步、加密還原、全域快捷鍵、系統匣與乘務記錄裡的工程行話全面翻成平白親切的手帳語感。桌機與手機同一版號。

## 主人會看到

### 跨模組輕量相片附件櫃、時間塊地點 ＆ 一日運行「當日生活掠影」
- **售票口票根附圖 & 清單零載圖徽章（桌機＋手機）**：
  - 記帳大票與手機記帳表單新增「票根・相片」區塊，每筆最多可附 4 張照片，支援從相簿選圖、手機相機拍照與剪貼簿直接貼圖，寫入前自動壓縮為輕量 WebP／JPEG（≤180KB）並支援端到端加密同步。
  - 清單與台帳完全不載入原圖，只在有附圖的列旁顯示克制小巧的相機張數標記；打開詳情才按需讀圖，點擊縮圖可進大圖燈箱左右翻看、補寫圖說或移除（手機支援返回鍵收起）。
  - 順手將售票口表單內的「不掛」統一潤飾為「不選」。
- **時刻表時間塊「地點」標記 ＆ 活動相片（桌機＋手機）**：
  - 編輯時間塊與補記表單新增「地點（選填）」與「活動相片」區，地點內建常用場所記憶補完（如圖書館、咖啡館、教室），分割與合併時間塊時自動延續原地點，時間軸與台帳精簡呈現 `@ 地點` 與小相機標記。
- **運行報告 → 單日跨頁「當日生活掠影」**：
  - 單日運行專頁左頁的時間投入列低調補上地點；若該日有票根或時刻表活動相片，左頁底部按需載入並呈現橫向「當日生活掠影」相片條（無照片日零佔位），點開燈箱可看圖說與來源，並可一鍵跳回該筆記帳或時刻表。

### 時刻表「行為鏈（計時模板）」一鍵連發
- **固定流程一鍵發車、一路點「下一站 ›」無縫換車**：
  - 發車台新增「直通 · 行為鏈」快選列，桌機頂部快速發車選單也同步支援從任意頁面一鍵啟動整條日常節奏（發車時自動帶入每站預設分類、預估分鐘、備註與地點）。
  - 進行中在時刻表底部列控（桌機與手機）以及桌機頂部迷你列車牌同步顯示步驟進度（如 `2/3`）與下一站預告，點一下「下一站 ›」立刻無縫切車，最後一站按「終點到着 ✓」完成全鏈，也能隨時「脫離」只離開行為鏈不中斷計時。
  - 「分類與設定」新增第 6 分頁「行為鏈」，內建三組起手範本（「晨間啟動」「專注連班」「睡前收心」）一鍵套用微調，完整接入加密同步。

### 底層系統與錯誤提示全面手帳化
- 將備份還原、雲端同步與憑證讀取、加密格式異常、全域快捷鍵占用、系統匣、外部助理連線與乘務記錄空狀態等底層提示，去除 `R2`、`SQLite`、`WAL`、`nonce`、`鹽`、`紀元`、裸英文錯誤與「工作日誌」等生硬用語，換成一看就懂發生什麼事、接下來該怎麼做的自然繁體中文。
