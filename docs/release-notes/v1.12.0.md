## v1.12.0 · 時刻表② 任務連動

時刻表和任務樹接上了。**在車票上按「発車」，那張票的時間就自己長出來**：時間塊可以連到車票、列車、車廂，或只連到一條路線；任務側板多了一列「時間」，整棵往上加總，正在跑的那一班每分鐘往上長。第一次從某條路線發車時問一次分類，之後同一張票、同一條路線直接沿用。桌機與手機同一版、功能對等。這一版**沒有新的資料庫 migration**。

### 主人會看到
- **今日頁發車**：
  - 電腦：滑過或選中一張票，列尾出現「▶ 発車」；鍵盤選中一列按 `N` 也能發。
  - 手機：票卡「⋯」裡多一項「発車」，右邊小字寫這次會用哪個分類。
  - 正在跑的那張票常駐一個「● 正在跑 1:53:47」，到站後消失。
  - 已蓋済的票不給発車（要替它補時間，用下面的「連到…」）；再按一次正在跑的那張只會說「已經在跑了」。
- **記住上次的分類**：先看這張票上次用的分類，沒有就看這條路線上次用的；都沒有（第一次碰到的路線、或沒掛路線的臨時車票）才跳出分類讓你選，選完就開跑。選錯了，toast 上有「換分類」。
- **發車台多一排「今日車票」**：分類格上方，左右滑；已蓋済的不放，正在跑的那張亮著。
- **「連到…」**：發車、改一塊、補記三個面板都有一列「連到」，可以搜尋全部任務、挑今日車票、只連路線、或取消連結。連到一張有上次分類的票時，多一顆「用『學習』発車」主鈕（`Enter` 也行）。運行列上的任務名也可以點來改。
- **任務側板的「時間」**：
  - 列車、車廂：原本的「花費」改叫「時間」＝整棵子樹的時間塊合計＋你手填的期初值；點開可以改手填的部分。
  - 車票、支線：只顯示合計，不給手填。
  - 路線：「本月 N・累計 M」，排在售票口的「花費」（錢）旁邊。
  - 滑過（手機點開）看「自己 N／底下 M」；正在跑的那一班會帶一個小點、每分鐘更新。
- **今日頁「專注」**改成「今天連到任務或路線的時間塊合計」，手機今日頁也補上了。
- **到處看得到任務名**：運行列、軸上的塊、通知欄、系統匣都寫「創作・寫契約」；連到的票被刪掉時寫「（原車票已刪除）」，復原後名字回來。
- **跑太久提醒多一層**：這一班的預估 → **連到的任務的預計時間** → 分類預設 → 全域。任務預計只套在正在跑的那一班，改了預計不會回頭翻掉以前的誤點記號。
- **蓋済時那張票還在跑**：跳一則「『X』蓋済了，計時還在跑」，附「到着」鈕；計時不會自己停。只有在這台蓋的才提示，別台同步過來的不提示。

### 底下換了什麼
- 時間塊的 `node_id`／`route_id` 兩欄（①a 就留好的）開始有值；連結兩欄一起寫、一起同步，切開沿用原連結，合併時留下的那塊保留自己的連結。
- 地基多了三個插槽：今日列動作（`todayRowActions`，可帶今日頁快捷鍵）、今日統計（`todayStats`）、任務側板「分量」段的欄位（`NodeFieldSpec.section`）；外加一顆檢查：線登記在核心範圍的快捷鍵，名稱必須帶自己的線名開頭。

### 這一版的邊界
- 兩台幾乎同時動手時：一台離線改了某塊的連結、另一台刪了同一塊，同步後那塊會回來；一台改連結、另一台合併，合併會被撤回、畫面上沒有提示。跟全 App「編輯勝過刪除」同一個規則，等提示做出來時刻表一起受惠；資料仍會兩台一致。
- 停在今日頁跨過一天的開始時間，再切到時刻表，時刻表會停在前一天，要等 App 回到前景才換日（①就有的行為，之後修）。
- 路線的「時間」手機上還沒有地方顯示，依路線看時間留到統計那一班。
- 兩台一台已更新、一台還是舊版的那段期間：舊版那台切開或補記時，切出來的片段照舊版規則處理連結（換分類切出的那段不帶任務），連好的任務不會被舊版清掉，兩台照樣一致。這一條是讀程式碼確認的，沒有實際用兩台混版跑過；兩台都更新完就不會遇到。
- 還沒有：統計與環比、日程視圖、塊／日視圖、荷札接軌。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝

- Windows x64：`NextStop_1.12.0_x64-setup.exe`（NSIS）。
