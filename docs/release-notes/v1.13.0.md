## v1.13.0 · 旅客筆記：捕捉小窗 ＋ 主線：同步復活提示

這一版同時出兩班：**旅客筆記的第五站「捕捉小窗」**——App 不在前面的時候也能隨手記一句，電腦按 `Ctrl+Alt+N` 叫出一張小捕捉票，手機從別的 App「分享」文字就收進收件匣；**主線的「同步復活提示」**——兩台各自改到同一筆時，現在會告訴你了。桌機與手機同一版。這一版**沒有新的資料庫 migration**，兩台可以分開升級。

---

## 旅客筆記⑤ · 捕捉小窗

### 主人會看到
- **電腦：`Ctrl+Alt+N` 隨時記一句**：不管正在用哪個程式，按下去螢幕中上方（滑鼠所在的那個螢幕）浮出一張跟 App 裡一樣的捕捉票，票根都在（收件匣／待辦／筆記／日記，還有售票口的「記一筆」）。打完 Enter 就存，焦點馬上還給原本的程式，可以接著打字；小窗會在原地蓋一下受付章再收起來。
- **點到外面就收起來，字留著**：小窗開著時點了別的視窗、按 Alt+F4，小窗收起；下次再按 `Ctrl+Alt+N`，剛剛打到一半的字和游標都還在。Esc 收起：打過字的要按兩下才放棄。
- **多行待辦一樣有預覽**：在小窗選「待辦」打好幾行，Enter 先長高成預覽框挑哪幾行變車票，Ctrl+Enter 建立。
- **系統匣右鍵多「記一句」**：忘了鍵位時的第二條路，放在「開啟 Next Stop」上面；時刻表的到着／換車照舊在最上面。
- **開機時啟動（縮在系統匣）**：設定〈一般〉多一列開關。第一次執行預設開——開機後不跳出主視窗、縮在系統匣，`Ctrl+Alt+N` 開機就能用；不想要就在這裡關。從桌面或開始選單點開 App，主視窗照常出現。
- **鍵被別的程式佔走會告訴你**：`Ctrl+Alt+N` 註冊不到時，啟動會跳提示和系統通知，設定〈一般〉也寫著原因；把佔用的程式關掉、回到 App 視窗，提示會自己消失。
- **快捷鍵頁多一列**：全域組多「記一句（App 不在前面也能用）　Ctrl+Alt+N」。
- **手機：從別的 App 分享文字進收件匣**：在瀏覽器、聊天或記事 App 選「分享」→「私鐵手帳」，文字直接放進收件匣，跳一句「收到分享，放進收件匣了」。App 沒開著也收得到；有標題的分享，標題放第一行；一次分享進好幾則時合成一句「收到 N 則分享」。

### 底下換了什麼
- 小窗是第二個視窗，啟動時建好、之後只藏起來不關掉；存檔走同一套捕捉流程，存完通知主視窗重讀。
- 主視窗改成由啟動參數決定要不要出現（開機自啟帶 `--minimized`）。
- 新增兩個桌機套件：全域快捷鍵、開機自啟（Tauri 官方 plugin）。手機不帶這兩支。
- 手機的分享走「先取、寫進收件匣後才確認」兩段，App 半路被關也不會丟。

### 這一版的邊界
- 同一段文字分享兩次會收成兩則（不去重）；寫進收件匣後、確認前剛好被系統關掉，也可能重複一則——手動刪掉就好。
- 手機沒有全域鍵、小窗、系統匣、開機自啟（Android 本來就不用常駐，分享時冷啟動也收得到）。
- 開機自啟關掉之後，Windows「啟動應用程式」清單裡可能還留著一筆停用的紀錄（自啟套件只刪了 Run 那一筆）；不會讓 App 自己啟動。
- 安裝路徑含空格時，開機自啟的指令沒有加引號（預設安裝路徑沒有空格）。
- 鍵位固定 `Ctrl+Alt+N`，還不能自訂；小窗不能拖、不記位置。
- 在捕捉框或小窗打完 `#荷札` 按 Enter，第一下會被荷札建議接走（荷札那一版就有的行為）。

## 主線③ · 同步復活提示

以前一台刪掉、另一台剛好改過的東西，同步後會默默回來；兩台改了同一格，也只有車票的乘務記錄記一行。這一版把這些事收進同步頁的一張小清單，同步完跳一句白話提示。同步的規則本身沒有改，只是讓你看得到。

### 主人會看到
- **同步頁多一區「最近兩台撞到的」**：桌機在設定〈同步〉，手機在右上 ⋯ → 同步。分兩組——「刪了又回來」（一台刪、另一台改過，改過的那份留下）和「兩邊都改了、後改的留下」（兩台改了同一格，例如同一則筆記的內容）。每一列寫幾點、哪一筆、往哪個方向撞；「兩邊都改了」那組會印兩邊各改成什麼（各取前 24 字）。平常沒撞到時，這一區不會出現。
- **刪了又回來，兩台都會說**：刪的那台看到「你刪掉的『○○』因為另一台改過，回來了」，改的那台看到「另一台刪過『○○』，但這台改過——留著」。兩台改了同一格時，只有被蓋掉的那一台會列出來。
- **同步完跳一句提示，按「看看」直接到清單**：只講這一趟新撞到的；同一批不會一直重複跳。手機從別的 App 切回來、桌機開機時，如果清單裡還有沒看過的，會再提醒一次；開過同步頁看過之後，重開也不再跳。
- **「知道了」一次清光**：清單看完按「知道了」就收起來。清單只存在這台、不會同步到另一台，兩台各自清。最多留最近 20 筆。
- **桌機點車票那一列，會直接跳到那張票**。
- **舊的那句「詳情在該車票的乘務記錄」不再出現**：車票的乘務記錄照舊會記競合的那一行。手機同步頁底下的說明也改寫成新的說法。
- **時刻表也受惠**：兩台同時一台合併、一台切開（或改了連結、類別）同一塊時間塊時，結果照舊是改過的那塊留下、被延長的鄰居切回原長，但合併的那台現在會看到「回來了」的提示，不會覺得記的東西莫名其妙變了。

### 這一版的邊界
- **不動資料庫（schema 不變）**：兩台可以先升一台，沒升的那台照常同步、只是沒有提示。
- 筆記、時間塊、帳目的列目前印泛稱（例如「筆記（a1b2）」），不能點；「兩邊都改了」那一列的欄位暫時印英文欄名、時間印成國際標準時間格式。各功能之後補上，就會印真名、中文欄名、點了能跳過去。
- 手機上車票那一列還不能點。
- 時刻表「與下一塊合併」碰上另一台改了被併的那塊、或兩台同時切開同一塊時，清單講的可能跟整理後的畫面對不上（例如寫的結束時刻跟畫面差幾分鐘）；時間不會丟，時刻表之後會把這裡講準。
- 一台重新加入同步之後，它第一次送上來的修改如果剛好跟另一台撞到，另一台這一次不會提示（這台自己照常會說）；之後就正常。
- 「兩邊都改了」那組如果太吵（例如排序位置兩台都動過也會列），之後再收窄。
- 加入同步、重新開始、改用某一份資料、還原雲端備份（回到過去）時，清單會清空，而且不會把以前的舊撞到一次灌進來。
- 刪掉一整串（例如整條路線連同底下的票）時，如果另一台改過其中一張票，那張票會照「編輯勝刪除」留下來，但它所在的路線已經刪掉、畫面上可能找不到；清單會列出它，這個情況本版不另外處理。

### 安裝
- Android（arm64）：`NextStop_1.13.0_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.13.0_x64-setup.exe`（NSIS）。
- 仍需自己的 Cloudflare R2（自用階段）。
