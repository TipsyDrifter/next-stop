## v1.14.0 — 售票口③ 管帳

預算、定期帳、加強版匯入，三樣一次到齊。這一版**新增兩張同步用的資料表**——桌機和手機請同一天升版（詳見〈安裝〉）。

### 主人會看到

**預算**

- **設定預算，統計頁多了一張卡**：切到「月」模式，三數卡下方出現預算卡。每個預算對象一列：左邊名稱、中間墨色進度條（加上一根細線標出「按今天日號推算應該花到哪」）、右邊「已用 X／預算 Y」和「剩 Z」。
- **總預算和分類預算各自設各自的**：可以只設總預算，也可以另外針對某個支出分類設預算（主分類或子分類都可以）；兩者各算各的，不要求加總對上。
- **預設金額套所有月份，想單月調整就覆寫**：「預設」那欄設好之後，沒有特別說明的月份都用這個金額。哪個月想調整就在「本月覆寫」欄填新金額，下個月自動回到預設。
- **超過預算立刻看得出來**：進度條填滿後尾端接一段斜紋，右邊的「剩 N」換成粗體「超支 N」。售票口的月曆，超過預算的那一天格子裡多一個小字「超」——一個月最多一格。

**定期帳**

- **固定會出現的帳可以設成定期**：每日、每週（選哪幾天）、每月（選哪幾號）都可以設。到了那天，App 自動記一筆；帳目清單每筆旁邊多一個小標「定期」，一眼認得出來。
- **忘了開 App 的那幾天也會補記**：規則起算日比今天早的，開 App 或同步完成後自動把漏掉的班補齊，每筆照各自的日期記。
- **從已有的那筆帳設起來最快**：打開任一筆帳的詳細頁，底部有「設成定期…」，會把那筆的分類、金額、帳戶、備註都帶過去，頻率預設「每月 N 日」。不知道從哪裡開始的，管理頁也有「＋ 新增」。
- **可以暫停、繼續、改、刪**：改金額只影響之後的班，已記的帳不動。刪掉一條規則有 10 秒鐘可以復原。已記的帳也可以隨時修改或刪除，不想讓某一班再被自動補回來的，刪掉就好。

**第二次匯入**

- **再匯一次財務管家備份，這次連預算和重複規則也一起搬**：備份裡的月預算和重複交易規則，現在也會匯進來。匯入可以重跑，不會重複新增。
- **匯進來的定期規則預設先暫停**：雙軌期財務管家還在跑，兩邊同時記同一筆會重複——所以匯入的規則先靜置，不自動實體化。
- **停用財務管家那天，到「定期帳」按「全部開始」**：這個按鈕只開始匯入進來、還沒開始過的規則，接著財務管家的下一班繼續記（已過的日期自動補記）；之後不要再用財務管家記帳。

### 底下換了什麼

- 新增兩張資料表：月預算表和定期規則表；帳目記錄表多了一個欄位，記錄每筆帳和哪條定期規則有關。
- 定期帳的實體化在啟動、同步拉完、以及跨過日界線時各觸發一次，確保班次不會漏。
- 匯入功能延伸到財務管家備份裡的預算和重複規則，流程和第一次匯入帳目是同一條。

### 這一版的邊界

- 預算只管支出；收入預算、年度預算後排。
- 預算金額以主幣別計算；外幣帳目折算後算進去。
- 定期規則只支援固定週期（每日／每週／每月）；完成後幾天再記一次之類的後排。
- 財務管家的重複規則只認「每月」這個週期；其他週期碼匯入時會在預覽卡說明略過的原因，之後版本補。
- 每月 31 日的規則在 2 月自動記在月底（有小提示）。
- 信用卡結帳日機制、貸款類帳戶的自動記帳後排。

### 安裝

**這個版本新增了兩張同步表。桌機和手機請同一天裝**——舊版本的 App 收到不認識的表會靜默丟棄那些變動，同一天升版才能確保兩端同步正常。

- Android（arm64）：`NextStop_1.14.0_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.14.0_x64-setup.exe`（NSIS）。
