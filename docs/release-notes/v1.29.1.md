# v1.29.1 · 桌機無縫品牌工具列（書封收合、迷你行先表示器、快捷三件套）與書溝陰影修復

這一版為桌機換上無縫融入「粉彩星空／銀河鐵道」的**專屬品牌工具列**，徹底告別系統原生白色標題列——左側深靛絨布書封與右側星空漸層直接延伸至視窗最頂端，並整合**書封側欄一鍵收合（`Ctrl+\`）**、**上下一頁歷史導航鈕**、**時刻表「運行中班次」迷你行先表示器**與**專屬快捷三件套（記一句、桌面置頂小窗、主題秒切）**；同時修復了書封右緣書溝陰影因捲軸預留槽偏移而露出的垂直亮邊。桌機與手機同一版號。

## 主人會看到

### 無縫雙區沉浸式品牌工具列（桌機）
- **告別原生白邊，書封與星空直通視窗最上緣**：移除 Windows 原生白色標題列，左欄 236px 深靛絨布書封與右欄天空漸層無縫延伸至視窗頂端；頂部空白處支援直接拖曳視窗與雙擊最大化／還原。
- **左上角：書封一鍵收合 `[◧]` ＋ 歷史返回／前進 `[←]` `[→]`**：
  - 嵌於書封最頂端，支援點擊或按快捷鍵 `Ctrl+\` 一鍵將左側書封收起／展開（自動記憶收合狀態）。
  - 當書封收起時，書溝陰影平滑淡出，左上角自動浮現 `[◧] [←] [→] ｜ 私鐵手帳` 迷你刊名，隨時可點一下展開書封。
- **右上角：「時刻表・運行中班次」迷你行先表示器**：
  - **計時中**：無論在哪一個分頁，右上角膠囊都會即時跳動秒數並顯示目前分類色點與分類／任務名稱；點擊膠囊可直達時刻表編輯該班次，按右側 `■ 到着` 即可一鍵結束計時。
  - **未發車**：顯示 `未發車 · ▶ 発車`，點擊即彈出常用分類選單，不必切換分頁就能一秒發車。
- **專屬快捷三件套 ＋ 品牌視窗控制鍵**：
  - 右上角常駐 **`✎` 記一句靈感捕捉**（`Ctrl+N`）、**`📌` 桌面置頂小窗開關**（開啟時亮起狀態提示）、以及 **`🌙 / ☀` 粉彩星空／銀河鐵道主題秒切**。
  - 最右端配置融入星空色調的最小化（`—`）、最大化／還原（`□`）與關閉縮小至系統匣（`✕`）按鈕。

### 書封右緣書溝陰影修復
- 修復書封右側的書溝立體陰影（`.page::before`）因頁面雙側捲軸預留槽（`scrollbar-gutter: stable both-edges`）往右偏移 10px、導致書封與陰影之間露出一條垂直亮白邊的問題，並還原粉彩星空原有的天頂光暈比例。
