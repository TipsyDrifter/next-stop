# v1.19.0 · 日記足跡接時間塊＋完整搜尋

下一輪第一班：翻到某一天，足跡裡也看得到那天的時間塊；找東西不再只有 Ctrl+P 的前幾十筆。桌機與手機同一版，**沒有新的資料庫 migration**。

## 主人會看到

### 日記足跡接時間塊（旅客筆記）
- **足跡最上面多一條日軸**：那天的時間塊照時刻畫成分類色帶（顏色跟時刻表同一組），済章是朱點、手記是空心點，一眼看出哪件事在什麼時段做完。平常畫 06–24 點，太早太晚的記錄自動往外延；滑鼠停在色塊上顯示分類、掛的車票和起訖。
- **最後一段「時間」**：當天總時長＋各分類合計（多的排前面），兩欄排；正在跑的那一班有呼吸的赭點。
- **済章旁寫花了多久**：那天掛著這張票的時間塊合計（例如「1h20m」）。
- **只有時間塊的日子也有足跡**；手機收合摘要多一句「記錄 7h40m」。
- **跟著時刻表即時更新**：足跡開著時，發車、到站、別台同步進來都當場跟上。

### 完整搜尋（任務／車票）
- **完整搜尋頁**：桌機按 **Ctrl+Shift+F**，或 Ctrl+P 走到最底「在完整搜尋看全部→」（Ctrl+Enter 直達）。結果不限筆數、往下捲接著載入。
- **搜得更深**：名稱、概要、乘務記錄都找；命中處有摘錄和底色。排序＝名稱 → 概要 → 乘務記錄，同層未完成在前。
- **篩選**：狀態／種類／路線（只列有結果的，附件數）。
- **點一列右邊看詳情**：側板照常改、蓋済；Enter 或雙擊跳到那張票所在的地方。離開再回來，字、篩選、位置都還在。
- **手機**：頂帶放大鏡進快速搜尋，最上面（或打字後清單底部）進全螢幕完整搜尋；篩選列左右滑、按返回回快速搜尋。

## 這一版的邊界
- 足跡的時間塊只能看、不能點跳到時刻表；月曆空心點照舊不算時間塊；只算掛在那張票上的塊（掛路線的不算進票）。
- 完整搜尋只搜任務／車票這一邊；筆記、日記、帳目、時間塊各有自己的搜尋；系統自己記的事件不算乘務記錄。
- 仍需自己的 Cloudflare R2（自用階段）。

- 手機：`NextStop_1.19.0_arm64.apk` 覆蓋安裝（同簽章）。
