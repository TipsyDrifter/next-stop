# v1.28.0 · 任務樹自由席自動升降格、支線摺疊與獨立專頁、封存與車庫項目刪除、售票口算式輸入與小算盤

這一版讓路線規劃與日常記帳都變得更有彈性：在路線或支線底下建待辦不用再煩惱「要先開列車還是直接建車票」，單層車票就是「**自由席**」，哪天想拆細項直接往底下加子車票就會自動升格成列車／車廂，子項刪光也會自動退回單張車票；支線除了能在大綱原地摺疊並顯示完成度進度條，也能點「**進入支線 →**」開成專屬的大綱／看板內頁；車庫與時刻表、售票口的已封存項目全面補上「**刪除**」按鈕（附即時復原與 30 天最近刪除保護）；售票口記帳金額欄則支援直接打加減乘除算式並內建小算盤。桌機與手機同一版，無資料庫遷移。

## 主人會看到

### 任務樹「自由席」演化（車票 ⇄ 列車／車廂自動轉換）
- **單層車票即「自由席」**：直接掛在路線或支線底下的單張車票會標示為「**自由席**」，有小事隨手開票就能上路，不必事先建一班空列車。
- **加子項自動升格、刪光子項自動退回車票**：當你在任何車票底下新增子車票、按 `Tab` 把下一張票縮排進去、或把別張票拖進來時，原本的車票會自動升格為「**列車**」（在路線／支線下）或「**車廂**」（在列車／車廂下）並換上進度環；反過來當底下最後一張子項被刪除或搬走時，也會自動退回單張車票，不會留下 `0/0` 的空殼列車。

### 支線摺疊收合 ＋「進入支線 →」獨立專頁
- **原地摺疊與迷你進度條**：桌機與手機大綱的支線列可一鍵收合／展開底下子項，右側同步顯示完成張數、百分比與迷你進度條。
- **支線獨立專頁**：點擊支線列的「**進入支線 →**」或支線徽章，即可聚焦進入該支線的專屬頁面，頂部具備完整的 `路線圖 › 幹線 › 路線 › 支線` 麵包屑可隨時退回母路線，支線內也支援獨立切換「**大綱｜看板**」視圖與快速新增列車／自由席車票。

### 開放刪除已封存與車庫項目 ＋ 統一車庫唯讀保護
- **不用先解封就能刪除**：
  - **車庫**：車庫書架的已到站幹線名牌（含底下無路線的封存幹線）、乘車記錄簿頁尾與路線頂部車庫橫幅新增「**刪除幹線／刪除路線**」。
  - **時刻表與售票口**：時刻表的已封存分類、目標、例行作息，以及售票口的已封存分類、桌機與手機已封存帳戶，全面補上「**刪除**」按鈕。
  - 所有刪除皆附帶底部 Toast「復原」按鈕，並納入設定頁「**最近刪除（失物招領）**」30 天保護（時刻表分類、收支分類、售票口帳戶現在都能從最近刪除一鍵撿回，且刪除分類或帳戶不會弄壞歷史紀錄）。
- **車庫唯讀邊界一致化**：已收進車庫的路線在聚焦進入支線或列車時，頂部會持續保留車庫提示橫幅；桌機與手機的大綱與看板統一攔截誤觸蓋章、拖曳、改名與多選，並提示「已收進車庫——要改先回到運行」。

### 售票口記一筆支援「算式輸入與小算盤」
- **直接打加減乘除算式**：在桌機售票口（主金額、外幣折算、轉入金額、餘額調整）與手機記帳金額欄，可直接輸入如 `120+45+80`、`500-120`、`(150+30)*2`（全形符號 `＋ － × ÷` 也能通），打字過程即時顯示琥珀金 `= 245` 預覽徽章，按 `=`、`Enter`、點預覽徽章、移開焦點或直接存檔都會自動算出結果。
- **內建票匭小算盤**：金額欄右側新增小算盤按鈕——桌機點開浮層小算盤、手機展開底部大按鍵小算盤面板，單手或滑鼠連點就能輕鬆湊單拆帳，不用再切出 App 開計算機。
