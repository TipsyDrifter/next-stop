# v1.24.0 · 車庫與回顧、週方針、每一頁都在正中間；售票口荷札與願望清單

第五本第一梯的後五班合在一版：跑完的路線收進車庫、駅スタンプ與年鑑；週一寫「週方針」；每一頁置中、路線一覽、支線變章節標題；售票口能掛荷札、記一筆就設定期、願望清單與帳戶頁；外加一處荷札改名的同步修正。桌機與手機同一版。**這一版帶三支資料庫升級（願望與常用票種、駅スタンプ、週方針）——兩台請一起升級**，還沒升級的那台會暫停接收另一台的變動，升級後補上。

## 主人會看到

### 車庫：跑完的路線收起來，不用刪
- 書封多了第三排「回顧」裡的「車庫」（Ctrl+8）；手機在右上齒輪的「更多」頁最上面。
- 在路線詳情、路線一覽的卡片、書封或手機路線清單幹線的 ⋯ 按「到站・收進車庫」：底下還有沒済的票會先問一句；收進去的票不再出現在今日和行程表，定期券先停下；可以馬上復原，之後也能在車庫按「回到運行」原樣回來。幹線也能整條收進車庫。收進車庫的路線不能再發券，要加先回到運行。
- 車庫裡的路線像書背立在書架上，寫済章數和到站日；點一本打開**乘車記錄簿**：開業到到站、幾枚済章、時刻表花了多少、記帳花了多少、掛了幾則筆記，經過的車站都在，四格數字點了直接跳到那個模組。
- **駅スタンプ**：發生過的事蓋一枚章——第一張票（開業）、車站到着、路線或幹線到站、路線開業滿一年、記帳滿一年，還有幾個累積的里程碑（第 100、1000 枚済，第 100 篇日記，某分類累計 100 小時）。蓋章那刻提示一次，之後不再提醒；沒有進度條、沒有「還差幾枚」、沒蓋的章不留空格。車庫下半是印譜帳，一個月一頁。
- **年鑑**：第二個分頁按月列済了幾張、寫了幾篇日記、哪些路線到站、蓋了哪些章，配一句那個月最後寫下的筆記；往年的今天寫過東西時最上面出現「那年今日」。「走行圖」分頁排在下一版。
- 路線圖頁首紀念章的金弧現在跟今日頁一樣代表「到了幾站」；搜尋找得到車庫裡的路線和票、標「車庫」；記帳、連到…、掛到哪這些選單只列還在跑的路線。

### 週方針：週一寫這週大致要完成的事
- 今日頁頂端多一張「本週方針」告示，行程表切到「週」也在最上面；手機在今日分頁頂端一行，點開是底部面板。
- 每句可以掛一條路線或支線，旁邊按「排成車票」就在那裡排一張這週的票，那句底下寫「已排 2 張・済 1」。済自己蓋；掛的那裡這週的票都済了會淡淡提醒「排的票都済了」。
- 週末回頭看：週日告示上多「回顧這週」；新的一週第一次打開，今日頁出「上週回顧」（手機是一行「回顧上週 ›」）——每句済了沒、掛的路線蓋了幾枚章、記了多久、花了多少；沒做完的一鍵帶到下週。
- 告示週一、週二預設打開，週三起預設收起，自己收或開過這週就照你的。沒有連續幾週、達成率這些分數。

### 每一頁都在正中間
- 寬螢幕上每一頁的內容放在畫面正中間、左右留白一樣寬。一行一行讀的頁（今日、路線圖、售票口清單、完整搜尋）寬度固定好讀；格子和圖表的頁（行程表、時刻表、旅客筆記、月曆與統計）跟著視窗變寬到一個舒服的上限。
- **路線一覽**：按側欄「路線圖」（Ctrl+2）先看到所有路線的一覽，每條一張卡：下一站、済了幾張、近 30 天花了多少時間和錢、有沒有誤點；點卡片進去，標題上方「路線圖 › 名稱」點回一覽；頁底「車庫 N 條 ›」。手機第一層也多同樣的數字。
- **側欄只放這一頁用得到的**：時刻表側欄改成正在跑的那一班、今天各組時數、本週目標、分類清單（點了只看它）；完整搜尋是三組篩選；旅客筆記多一行小標、收件匣可只看筆記或只看車票；今日、路線圖、行程表照舊是「我的路線」。
- **支線、列車、車票一眼分得出來**：支線變成章節標題（一行大字、「4 班・済 1」，沒有検印與日期）；支線和路線底下都可以直接放車票；有子項的列車検印欄變成進度圈（2/5），全済畫滿、旁邊寫「可以蓋済」但列車還是要自己蓋；「＋ 新增 ▾」分列車、車票、支線三種各寫一句用途；列車轉支線時車廂跟著變列車（反過來也一樣）。

### 售票口：記帳更順手
- **記一筆就能設定期**：表單裡多一列「不重複｜每日｜每週｜每月」；記好的帳也能在同一列「設成定期」。
- **備註會記得**：打一兩個字就列出以前寫過的，點一下填好；手機的備註和定期從「更多欄位」拿出來了。
- **帳目可以掛荷札**：跟車票、筆記同一套；搜尋可用荷札篩、統計多「依荷札」、捕捉框打 `#京都` 就掛上；定期帳也能掛，之後自動記的每一筆都帶。
- **常用票種**：常記的那幾筆存成小卡，點一下整張填好。
- **願望清單**：頁首多一格「願望」，想買的先記著，買了按「買了」就填進記一筆。
- **帳戶頁**：頁首多一格「帳戶」，一眼看全部帳戶的餘額、本月進出、近半年走勢，新增、封存、排序都在這裡。
- **分類可以再分下去**：子分類底下能再建子分類，層數不限；可用「移到…」或拖曳換到別的分類底下；統計可一層一層「進入」看。**兩台都升級之後再建第三層**。
- 帳戶、分類、常用票種、願望都能直接拖著排；今日頁統計列寫一句「定期 1 筆 −12,000」點了直接開那筆；手機售票口頁首五格平均分配寬度。拿掉「從財務管家匯入」（搬家已完成）。快捷鍵：售票口頁 `4` 帳戶、`5` 願望。

### 修正
- **荷札改名，另一台早一步掛的東西也跟過去了**：一台把 `#京都` 改名成 `#旅行/京都`，另一台在同步前先掛了 `#京都`——以前那一處會留在已經不見的舊名上；現在同步後一樣跟到新名，筆記和日記裡寫的舊名也一起改。之前已經發生過的，升級後第一次同步到東西時會自動整理好。
