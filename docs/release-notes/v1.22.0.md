# v1.22.0 · 收官磨光：手機備份與還原、體檢斷點清零

第四本收官體檢（走全產品動線）抓到的斷點與不一把尺，一次修完；最大的一件是手機補上完整的「備份與還原」。**0 migration**，資料格式不變。

## 主人會看到
- **手機有自己的〈備份與還原〕了**（更多 › 備份與還原，在同步列之前）：自動備份、立即備份、備份清單與「還原到這份」都和桌機一樣；桌機的「第二備份位置」手機改用「另存一份…」（把備份存到下載或雲端硬碟，換手機時在新手機按「從檔案還原…」接回）。重新開始（危險區）現在兩台都會先在這台留一份本機備份才清。
- **今日頁連續新增臨時車票不再長出重複票**：以前輸入框的字建完不清、連按 Enter 會同名再建好幾張；現在建完清空、連打各建一張，失焦也只建一張。
- **還原後外部助理不再「連接埠被占用」**：以前 App 自我重啟（還原、重新開始）後，新行程會被舊行程殘留的埠卡住，要手動完全關掉再開；現在重啟後幾秒內自己接回來。錯誤句也改成講人話、指路怎麼解。
- **車票欄位兩殼同一把尺**：桌機車票（和列車、車廂）側板補上「票種、締切日」；手機車票詳情的「心情」拿掉（心情是列車／車廂完成卡的事，照規格「朱只給済章」的同一精神）。
- **小修一批**：收件匣臨時券的票號改用全 App 統一格式、meta 改「10/28 建立」不再黏字；時間軸翻到過去日期的摘要寫日期、不再寫「今日已記錄」；統計的環比註腳改白話（「比的是上週同一段時間：…」）；補記／改塊面板的副標跨日時帶日期（「13:00 – 10/28（三）03:00 ・ 14h」）。

## 底下換了什麼
- MCP 接口的埠改用不可被子行程繼承的方式綁定＋重試（根因：Windows 上舊行程的 listener 會被重啟後的新行程繼承）。
- 備份模組兩殼都編；手機掛上備份指令與 SAF 另存／選檔。
- 讀取面的日界線守門改讀設定值，不再寫死 03:00。
- 全部經沙盒與 AVD 實測（備份→另存→還原來回、還原觸發重啟），正本零接觸。

## 這一版的邊界
- 手機「另存一份…」只能另存備份清單裡的檔（防呆）；同步頁的「匯出到手機」（JSON、只能人工翻閱）照舊是另一種東西。
- Android 平板撐到桌機版面時會看到手機做不到的「選擇資料夾…」（邊角，記著）。
- 仍需自己的 Cloudflare R2（自用階段）。

## 安裝
- 桌機：`NextStop_1.22.0_x64-setup.exe` 直接升級安裝。
- 手機：`NextStop_1.22.0_arm64.apk` 覆蓋安裝（同簽章）。
