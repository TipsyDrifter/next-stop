# v1.31.0 · 昭和車廂銘板運行計時器、有限度圓角五階層制度、途中下車結案印記分區、票面直覺快改與天象設定統合

這一版落實依文具與鐵道器物材質分工的「**有限度圓角五階層制度**」，並將桌機頂端工具列的運行列車計時器換上「**昭和車廂金屬銘板風**」（`7px` 銘板圓角外框 ＋ `2px` 種別微圓小章 ＋ 方向幕實線分格 ＋ 票根虛線撕線）；在任務與排程體驗上，自動將任務樹無子項的空列車／車廂對齊為可排程車票，確立「**途中下車**」為結案印記（退出誤點與待辦計數，並在詳情面板拆分為「推進狀態 vs 結案印記」），補齊誤點票點擊「原定／締切」原地改期與點擊票根快速改掛路線；同時將設定頁散落的動態天象選項收攏成一張清晰的「**今日天象與動態氛圍**」區塊，並修復跨模組跳轉後的返回鍵原子導航。桌機與手機同一版號。

## 主人會看到

### 昭和車廂金屬銘板風「運行列車計時器」與全站「有限度圓角五階層制度」
- **工具列運行列車計時器換裝「昭和車廂金屬銘板風」**：
  - 外框採用 `7px` 銘板圓角搭配上下左右俐落微直邊、紙底上緣微反光與運行中淡赭描邊，宛如老電車車廂壁上釘著的琺瑯番號銘牌。
  - 內部導入鐵道方向幕與硬券結構：**`2px` 種別微圓小方章**（未發車空車時轉為虛線空心章）｜**等寬時刻 `1px` 實線分格**｜**任務行先** ┊ **右側 `1px dashed` 票根虛線撕開「`■ 到着`／`▶ 発車`」**，在粉彩星空、銀河鐵道等六套亮暗主題下皆清晰耐看。
- **全站「有限度圓角五階層制度」剛柔並濟**：
  - **操作控件守方正（`2px`）**：按鈕、分段切換、輸入框、時刻表釘選分類與統計篩選 chip、多選荷札 chip 統一維持裁紙刀切出的俐落方角。
  - **厚磅車票與紙卡微倒角（`4px`／暗色 `3px`）**：車票、手札紙卡、側板浮層與時刻表待排班次小票保留硬券挺度。
  - **書籤浮標與車廂銘板留柔角（`6px`／`7px`）**：理想手札相片浮標、年代書籤、支線聚焦籤與售票口算式預覽籤採溫和微圓角。
  - **迷你角標計數珠與動態信號燈留圓潤（`9999px`）**：書封與手機導航圖示上的迷你計數珠、今日列「正在跑」信號燈與 Toggle 滑軌維持圓潤，不以尖角刺傷圖示；手機底部抽屜上緣統一拉齊為 `12px`。

### 任務樹葉節點自動對齊車票 ＆「途中下車」結案印記分區
- **空列車／空車廂存量自動回填為車票**：
  - 啟動時自動將底下沒有子項目的空列車／空車廂轉為「**車票**」（單層掛於路線／支線下即為自由席／區間乗車券），不再出現掛著列車圖示卻無法排入今日與時刻表的孤立節點。
  - 統一大綱編輯的自動升降格：在車票底下新增子項或按 `Tab` 縮排時，母節點自動升格為列車／車廂；刪光最後一張子車票時，母節點自動退回單張車票。
- **「途中下車」退出誤點與待辦計數 ＋ 詳情面板雙區印記**：
  - 蓋上「**途中下車**」的車票正式歸入結案封存狀態——不再列入今日頁「延着（誤點）」清單、不計入左側書封與手機導航待辦數字，也不再觸發締切逾期提醒。
  - 桌機詳情側板與手機狀態抽屜將原本擠在同一排的四態拆分為兩列：「**推進狀態**（`未開始 ｜ 進行中`）」與「**結案印記**（朱色圓印 `済` vs 墨色方印 `途中下車`）」，結案後一眼看出蓋的是哪一枚章，並支援按「退回進行中」一鍵撤銷結案。

### 車票票面直覺快改（誤點改期・票根改掛路線・未排程快排）
- **誤點票「原定／締切」原地點擊改期**：今日頁誤點車票上的「`原定 M/D`」與「`締切 M/D`」由純文字改為可點擊虛線籤，點一下即原地彈出日期快選與月曆。
- **點擊左側票根快速改掛路線**：車票左側的票根（路線圓牌與路線名）升級為互動按鈕，不必打開詳情面板就能原地改掛到其他路線、支線或列車下；路線大綱行內編輯亦支援直接調整掛載節點，未排程車票滑過或展開即可快速排定乘車日與優先級。

### 設定〈一般〉「今日天象與動態氛圍」統合區塊 ＆ 跨頁原子導航修復
- **設定〈一般〉三段分組與天象統合卡片**：桌機設定〈一般〉與手機「更多 › 設定」共用同一套結構，依序收攏為「**外觀**」、「**日子怎麼算**」、「**開機與其他**」三組；原本散落的氛圍開關整合為一張「**今日天象與動態氛圍**」卡片——上方「天象節律」主開關附一句話動態說明，下方分列「天色流轉（晨昏與入夜染光）」、「經過的景物（列車・候鳥・流星）」與「濃淡」，切至關閉時細項整層柔和淡出、不再突兀跳動。
- **跨模組跳轉返回一次到位**：將跨分頁帶選取目標的跳轉（例如從今日車票、日記當日足跡或快速搜尋跳往目標項目）收斂為單筆原子歷史紀錄，按滑鼠側鍵或返回鍵一次就能乾淨退回出發頁，不再卡在中間狀態。
