# v1.20.0 · 手機能動手改＋外部助理

下一輪第二班（合併版）：手機從「只能看」變成「能動手改」——路線圖、詳情、路線管理整套都開了；桌機多了〈外部助理〉，讓 Claude 直接讀寫你的手帳。桌機與手機同一版，**沒有新的資料庫 migration**。

## 主人會看到

### 手機：路線圖可以直接改了
- **每一列都能操作**：右邊有検印鈕和「⋯」。在「⋯」裡可以新增、升層／降層、上移／下移、改名、記乘務記錄、改期、運休、移動到別處、刪除；做不到的項目會淡掉，點了會說原因。空的路線也有「新增第一班」鈕。
- **車票詳情頁**：「⋯ → 詳情…」打開整頁詳情，跟電腦版側板一樣能改：名稱、概要、現況、優先順序、票種、重複設定、執行日、締切日、幾點、心情、乘務記錄、本班済／運休、轉為支線／列車、移動、刪除。
- **在手機上管理路線**：可以新增幹線和路線（取名、挑顏色、代碼）、改名、換到別的幹線、刪除（可以復原）；路線詳情頁裡也能管理車站。路線清單空著時，直接按「新增幹線」「新增路線」開始。
- **蓋完列車會跳完成卡**：順手選心情、記一句這一趟做了什麼；不想記就按「跳過」。
- **今日的車票可以長按拖曳換順序**（有時刻的票照時刻排，不能拖）。
- 「⋯」選單重新整理：排程選項排成一列，移動和排序收進「編排」；「清除執行日」收進「日期…」。
- **需要重新啟動的地方（雲端還原、重新開始）現在會自動重開 App**，不會再像閃退一樣直接關掉。

### 外部助理（新，桌機）
- **讓 Claude 直接看你的手帳、幫你排行程**：設定多一頁〈外部助理〉。連上之後可以跟 Claude 說「今天有什麼」「把這三件事排到下週」「記一筆午餐 120」，它會直接在私鐵手帳裡讀寫，畫面跟著變。
- **每個功能自己決定開多少**：任務、時刻表、筆記、日記、帳目各一組「關／只看／可改」，一開始全部關著。關著的功能，助理會收到「沒有開放」，App 也會提醒你去設定。
- **一次排好幾件事會先給你看方案**：助理先列出每件排到哪天幾點、那天已經有幾件，你同意了才寫進去。
- **刪掉的東西可以復原**：助理刪了車票、筆記、時間塊或帳，角落的提示可以按「復原」。
- **怎麼接**：設定頁有「複製 Claude Code 指令」和「複製 Claude Desktop 設定」兩顆鈕，貼上就好。

### 電腦版小改
- 列車、車廂、車票的詳情側板多了「概要」欄。
- 改路線代碼時自動轉大寫、最多 4 個字，跟新增路線一致。
- 每週重複只剩一天時再點掉，會提示「每週至少要選一天」。

## 修好的問題
- 今日頁和行程表的「誤點 N 件」算法不同（差在今天已済的那張）——兩頁現在數法一致。
- 從今日頁打開一班還有未完成子項的列車，在側板改成「已完成」時沒有先問「連同 N 個一起完成？」——現在會先問。
- 手機的提示訊息在頂端時會讓開錯誤提示列；「移動到…」一打開就在目前所在的路線。
- 検印連點兩下不會再蓋到下一班。

## 這一版的邊界
- 外部助理只在這台電腦、App 開著時有效（縮到系統匣也算）；手機不能連，手機的資料會同步到電腦。
- 助理不能把事情排到過去；過去的事請在 App 的日期欄補記。
- 連線金鑰重新產生後，已經接上的助理要重貼一次。
- 仍需自己的 Cloudflare R2（自用階段）。

## 安裝
- 桌機：`NextStop_1.20.0_x64-setup.exe` 直接升級安裝。
- 手機：`NextStop_1.20.0_arm64.apk` 覆蓋安裝（同簽章）。
