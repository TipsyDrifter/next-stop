## v1.1.4 通車前整備・雲端備份＋真撤銷密語

2026-09-25 主人真機驗收：桌機拍一份雲端快照 → 手機不經電腦直接「回到過去」→ 桌機改密語並換掉資料鑰匙 → 手機用新密語重新加入、未送出的修改一起併回 → 手機把匯出檔存到自己選的位置。九步全過；手機從 1.1.2 直接跳上來也不用重新配對。

### 主人會看到
- **雲端備份**：每台裝置每天第一次同步成功後自動拍一份加密快照上雲，也可以手動「立即備份到雲端」。桌機〈備份與還原〉與手機〈同步〉都能列出所有裝置的快照，點一份就能「回到過去」或「接上現在」，字和後果與桌機本機還原完全一樣。保留規則是階梯式：最近 14 天全留、之後每週留一份留 3 個月、再之後每月留一份留 1 年。
- **改密語多一個勾選「同時換掉資料鑰匙（讓舊密語真的失效）」**：不勾＝照舊毫秒級改密語；勾了＝換一把新的資料鑰匙、雲端全部重新加密、舊紀元清掉，抄走舊密語加桶的人從此什麼都解不開。其他裝置會停在「鍵違い」，狀態列正下方直接有「用新密語重新加入」，四個欄位不用重填，還沒送出的修改會在加入時一起併進來。
- **忘了密語**：已加入的裝置在〈密語〉頁把「現在的密語」留白就能直接設新的；換鑰匙時若忘了密語，畫面會告訴你先這樣做。
- **手機「匯出到手機」**改成系統的檔案選擇器，可以選「下載」或任何位置；還沒加入同步的手機也有「先存一份到手機」。
- 舊紀元會自動清理（只留最近兩個）；同步頁若有因欄位不齊而略過的資料會顯示筆數。

### 底下換了什麼
- 快照＝全量 JSON 用資料鑰匙封裝，存 `v1/snapshots/`；還原走「留底 → 匯入 → 既有還原標記 → 重啟收尾」，不新增第三種還原流程。
- 換鑰匙走七步（新紀元當鎖、重封 KEY 為提交點、重加密快照、刪舊紀元），中途關掉 App 會自動接著做完，提交點之前中斷則自動回滾。
- 手機自動留底改為先拍一份雲端快照（不再依賴寫不進下載目錄的路徑）。
- `sync_meta.role` 已移除：**這一版起不能退回 1.1.2**。

### 已知限制
- 換鑰匙那台若中途遺失且已過提交點，舊紀元要等它回來才會清乾淨；請在不會離手的那一台做。
- Android 的「重新啟動」實際上是關閉 App，雲端還原後請手動重新打開。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝
- Android（arm64）：`NextStop_1.1.4_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.1.4_x64-setup.exe`（NSIS）。
