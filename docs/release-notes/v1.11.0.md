## v1.11.0 · 主線② 車票預定時刻

車票可以寫幾點了。填上時刻後，今日頁的票照時刻排好，行程表也可以切成時段視圖，一眼看出一天的事怎麼分佈。這一版帶資料庫更新，兩台都要升級。

### 主人會看到

- **車票可以填幾點**：車票側板多了「幾點」欄。填上 `14:00` 後票面印「14:00 発」；同時填了預計就印「14:00 発・90 分」，側板顯示「→ 15:30 着」。隔天凌晨的事寫成 `25:00`——日界線 06:00 時，凌晨一點填 `1:00` 自動換算成 `25:00`，排在今天最後；存的字就是看到的字，不用另外換算。

- **今日頁照時刻排**：有填時刻的票照幾點排在前面，沒填的接在後面維持手排順序。頁首多「下一班 HH:MM」；現在線橫過票列標出現在幾點；已過時刻、還沒入鋏也沒蓋済的票，時刻字轉赭。

- **行程表多一種「時段」排法**：桌機行程表的分段鈕多一個「時段」（月｜週｜時段｜串流），一次看完一週——有時刻的票畫在幾點的位置，高度對預計時間；沒填預計的固定高度、底邊虛線淡出、標「長度未定」。手機行程表也可切成「時段」，一次看 3 天，左右橫滑換頁。

- **定期券有每班時刻，也能只改這一班**：定期券側板可以設一個時刻，每一班都繼承。也可以只改某一班（桌機在側板検印段的「本班」，手機在票卡 ⋯ 的「本班改時刻…」），只調整那一班、其他班不動，票面多一個靛色小字「本班」；「改回每班時刻」一步還原。

- **手機用滾輪選時刻**：手機票卡 ⋯ 裡有「幾點…」，開啟滾輪，小時欄照日界線排（06–29）；常用幾個時刻列在上面直接點；「不排時刻」也在那裡。

- **車票側板補了「預計」欄**：乘車券的側板以前沒有「預計」，現在補上，填完即時顯示到站時刻（「→ 15:30 着」）。

- **搜尋打 % 或 _ 不再亂**：Ctrl+P 搜票名，以前含 `%`、`_`、`\` 的查詢會把全部票列出來；現在只找名稱真的含那個字的票。

### 這一版的邊界

- **帶資料庫更新（schema 9），兩台都要升級**：只升一台時，沒升的那台會暫停吸收新版寫的東西，同步頁顯示等待；升級後自動補齊，不會壞資料。
- 建票時不會從票名裡解析時刻（打「14:00 買菜」不會自動填時刻）。
- 行程表的月格不印時刻，週格也不印；要看時刻去時段視圖、串流或今日頁。
- 跨機同時改同一張定期券不同班的時刻，只留改得比較晚的那台的那項（另一台改的那班覆寫消失，乘務記錄一行說明）。
