## v1.1.3 通車前整備・同步規則重整（三條規則、密語可改）

2026-09-22 主人真機驗收：升級後桌機直接「已加入」，不重配、紀元不變。這一版把同步規則從六條特例收成三條，是查了 19 個產品（Things 3、Obsidian Sync、Actual Budget、Syncthing、Apple、Signal…）之後照成熟做法重寫的。

### 主人會看到
- **只剩三條規則**：①加入同步——任何一台都可以是第一台；這台空的直接拉，兩邊都有資料問一次「兩邊都保留」或「改用另一台的」。②還原（桌機）——「回到過去」（所有裝置改用這份）或「接上現在」（只這台換成備份）。③重新加入——拿掉再放回，回到①。
- **密語可以改**：資料改用隨機資料鑰匙加密，密語只負責把鑰匙包起來放雲端；改密語不重傳、其他裝置不用動。忘了密語也有出口（現密語留白）。
- **換 R2 token 不必重新加入**：多了「更新憑證…」。
- 正本／副本、配對時清空、預覽選方向——全部退場；配對碼只是省手打的便利。
- 改正待ち 提示會顯示筆數與時間跨度；密語打不開雲端上的東西時有可見狀態（鍵違い）。

### 底下換了什麼
- 單一入口 `加入同步`：先看雲端桶——空＝第一台；有＝直接拉或問一次；紀元與鹽一致＝同一份資料重接，只更新憑證。鹽存在桶裡（`v1/SALT`），兩層鑰匙存 `v1/KEY`。
- 裝置身分放系統鑰匙圈／App 私有檔，不放資料庫：複製資料夾＝新的一台，備份還原不換身分。
- 合併用原始時間戳（不再把整台蓋過去）；還原兩選項走標記檔；紀元「拆得開即承認」。
- v1.1.2 → v1.1.3 自動遷移，不重配。

### 已知限制
- 舊密語配上舊鑰匙物件的副本仍解得開資料鑰匙；真正撤銷（換資料鑰匙重加密）排 v1.1.4。
- 手機沒有備份三件套，所以手機沒有②；雲端快照備份排 v1.1.4。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝
- Android（arm64）：`NextStop_1.1.3_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.1.3_x64-setup.exe`（NSIS）。
