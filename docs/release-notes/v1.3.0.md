## v1.3.0 · 旅客筆記② 日記・當天足跡

旅客筆記多了第三區「日記」。以日為單位，一天可以寫好幾篇、沒寫的日子回頭補記；旁邊自動排出那一天的足跡——蓋了済章的車票、寫下的乘務記錄、點過的心情——不用自己抄一遍。桌機與手機同一版、功能對等。這一版沒有新的資料庫 migration，升級不動舊資料。

### 主人會看到
- **日記頁**：旅客筆記頁內新分區「日記」（桌機側欄、手機上方第三段）。大日期可點開挑日子，左右翻日、一鍵回今天，翻不到未來。桌機 `←`／`→` 翻日、`Home` 回今天、`G` 跳到某天。
- **月曆記號**：桌機左側月曆、手機頂部月份條，有寫日記的日子實心點、只有足跡的空心點；今天之後灰掉。
- **寫日記**：按「寫日記」（桌機 `W`，`Ctrl+Enter` 存；手機按「存檔」，Enter 是換行）。篇頭標「寫於 HH:MM」；翻到以前的日子寫就標「（補記）」。一天可以「再寫一篇」。點一篇進打字、離開自動存。可以改日期、刪除，都能在 10 秒內復原。
- **搜尋**：桌機按 `/`、手機搜尋框，列出跨日的結果，點一則跳到那天。
- **當天足跡**：日記旁（手機在下方、可收合）自動列三段——「蓋了章的」「寫下的」「心情」。足跡可以自己翻到別天看，有「回到 M 月 D 日」拉回來；什麼都沒做的日子寫「這天沒有留下足跡」。
- **從別處記進日記**：捕捉框多了第四枚票根「日記」（`Ctrl+N` 後 `Tab` 切過去；手機浮動筆鈕點「日記」），存下去就在今天的日記裡。收件匣與筆記頁多了「記成日記」（桌機收件匣按 `D`），那則搬進它寫下那天的日記，可復原。
- **這次一起改的**：
  - 受付章放大到 42px。
  - 臨時券標題全 App 統一黑體（今日頁、日曆當日清單都是）。
  - **字型內建**：手寫字（乘務記錄、誤點註記）與票號字體隨 App 附帶，離線也在，不再靠網路載入。
  - 側欄第二排「旅客筆記」那枚改成和第一排一樣的大圖示。
  - 設定頁新增「每週從星期幾開始」（預設週一），日曆與旅客筆記月曆跟著走，兩台同步。
  - 設定→「重新開始」的說明補上「筆記」。
- **兩台一起**：日記隨既有的端對端加密同步往返。你在手機上正打一篇、桌機把它刪掉，手機上那篇不會突然消失，打完離開才不見；桌機按「復原」兩台都回來。

### 底下換了什麼
- **日記＝筆記表的一種**：`notes` 表加 `kind='diary'`，`entry_date` 是歸屬日（依日界線）、`noted_at` 是寫下的時刻，兩者不同就是補記。不新增表與索引，**沒有新 migration**。
- **字型檔進 App**：Iansui（芫荽）、Noto Sans TC、Noto Serif TC、Fraunces 四套連同 SIL OFL 授權檔一起打包（`src/assets/fonts/`）。安裝包因此各多約 19MB。
- **設定同步多一鍵**：`week_start` 進同步白名單。
- **共用日期挑選器**：抽成 `src/ui/common/DatePicker`，今日頁的「推遲到某天」也改用同一顆。
- 捕捉框的票根改四枚；側欄通車圖示樣式收進共用的 `gnav.css`。

### 這一版的邊界
- 還沒有：荷札（日記篇只留了掛牌的位置）、Markdown 排版、`Ctrl+P` 搜日記、日曆視圖當日清單的日記入口、每日回顧／那年今日、flomo 匯入、足跡的時間塊（等時刻表通車）、手機日記的鍵盤快捷鍵。
- 日曆頁格子上的日記小點，在日曆頁記了日記後要翻一下月份才會出現。
- 兩台若日界線設定不同，同一篇的「補記」標記可能一邊有一邊沒有；歸屬日本身不會漂。
- 同步引擎既有的「編輯勝刪除」規則：對方剛改過的筆記或日記，你刪掉後下次同步會默默回來、沒有提示。要不要補提示另案處理。
- 心情燈號的紅是赭色，朱紅只給済章——是設計。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝
- Android（arm64）：`NextStop_1.3.0_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.3.0_x64-setup.exe`（NSIS）。
