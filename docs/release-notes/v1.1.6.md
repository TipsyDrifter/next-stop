## v1.1.6 通車前整備・重新開始

這一版回應真機回饋「想把資料庫清乾淨重來」：〈備份與還原〉多了正式的危險區，可以只清一台，也可以讓所有裝置一起重新開始。清之前一定先留一份備份，而且要親手打字確認。

### 主人會看到
- **危險區**：桌機在〈設定 › 備份與還原〉最底、手機在〈更多〉最底。兩顆鈕：
  - **只清這台**：先拿掉這台的同步設定，再清掉車票、班次與乘務記錄；主題、日界線等設定保留。其他裝置與雲端都不動，之後按「加入同步」就會把雲端那份拉回來。
  - **所有裝置一起重新開始**（加入同步後才能按）：這台清空、雲端換上空的一份；其他裝置下次同步會看到「另一台重新開始了」，按「一起清空」才會跟著清（各自會先留一份）。同步身分與密語都保留。
- **三層保護**：清之前先留底（桌機本機備份一份；加入同步的話再上傳一份雲端「保險」快照；手機沒加入時匯出成檔）→ 要打「清空」兩個字確認鈕才會亮 → 確認窗講清楚會發生什麼。任何一份留底沒成功，這台一個字都不動。
- 清錯了也救得回來：從〈雲端備份〉列表點那份「保險」→「回到過去」。**後悔要趁早**：雲端那份兩週內一定救得回（之後每週只留最新一份，會被之後每天的空庫快照取代）；本機那份會隨每天的自動備份輪替掉（保留幾份就約幾天）。
- 手機沒加入同步時按「只清這台」，會先請你選一個位置（例如「下載」）把整份資料匯出成檔；取消就不清。
- 另一台按了「所有裝置一起重新開始」之後，別台的首頁橫幅與系統通知會寫「另一台按了重新開始…按『一起清空』」；按完畫面立刻變空（不必重開）。
- 完成後桌機會重新啟動；手機會關閉，請自己重新打開。
- 加入同步的表單多一句說明：那四行是 R2 桶的門牌與鑰匙，密語是另一回事。

### 底下換了什麼
- 「所有裝置一起」沒有新增同步流程：清空之後沿用「回到過去」的收尾開一個空的紀元（標記 `reason=reset`），別台走既有的改正待ち，只換字。
- 別台偵測新紀元時，重新開始開的空紀元不再被當成「對方還在寫」而跳過。
- 重新開始之後、任何一台寫下第一筆之前有裝置「加入同步」：沿用那個空紀元（不再另開第三個）；加入的那台若還有資料，會先被問「兩邊都保留／改用另一台的」。
- 同步狀態還沒處理完時，按危險區的鈕當場就會告訴你原因，不必先打「清空」、也不會白拍一份備份。
- 開發模式的「重置空庫」鈕由正式入口取代。

### 已知限制
- 同步狀態還沒處理完（改正待ち、鍵違い、換鑰匙中）時不能重新開始，會告訴你先去同步頁處理。
- 留底不是永久的：本機那份跟每天的自動備份共用保留份數，雲端那份兩週後可能被同一週較新的快照取代。
- 手機匯出的檔只能人工翻閱，App 目前不能從檔案匯入；要救回請用雲端「保險」快照。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝
- Android（arm64）：`NextStop_1.1.6_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.1.6_x64-setup.exe`（NSIS）。
