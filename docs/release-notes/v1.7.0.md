## v1.7.0 · 旅客筆記③ 荷札

旅客筆記的第三班車：**荷札**（標籤）上線了。筆記、日記、車票都能掛上荷札，像在行李上繫一張小木牌——同一則東西可以繫好幾張，之後從任何一張牌都找得回來。桌機與手機同一版、功能對等。這一版有新的資料庫 migration（0008），升級時照舊先備份再升級、舊資料不動。

### 主人會看到
- **荷札**：筆記與日記的編輯器裡打 `#` 就能掛牌（打字時有即時建議）；車票從任務側板、手機票卡的「⋯ → 荷札…」掛。
- **旅客筆記頁的荷札段**：書封列出所有荷札與數量，點一張牌就看繫著它的所有東西（筆記、日記、車票混排的清單頁）。
- **快速跳轉**：`Ctrl+P` 打 `#` 直達荷札。
- **日記側欄月曆的記號**：有寫日記的日子畫記號（月格自畫，今日與推遲行為零變）。
- **手機**：四段式旅客筆記頁加入荷札段；收件匣臨時票也能掛牌；刪掛牌的票，荷札數量即時跟著變。
- **刪除**：荷札可刪（確認面板會說清楚牌子拿掉、東西都留著）；同步照舊端對端加密。

### 底下換了什麼
- **兩張新同步表 `tags`、`taggings`**（migration 0008）：荷札與繫結關係跟著既有同步往返。
- 三個新的登記式插槽進了地基（任務側板欄位、快速跳轉字首、手機票卡選單項），之後任何一條線都能用同樣的方式掛進這些位置。

### 這一版的邊界
- 荷札的搜尋與批次整理（改名合併之外的進階操作）排在之後的階段。
- 還沒有：旅客筆記的全文搜尋強化、主題商店字型庫。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝
- Android（arm64）：`NextStop_1.7.0_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.7.0_x64-setup.exe`（NSIS）。
