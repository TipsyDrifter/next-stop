# v1.26.0 · 候車室、路線看板與篩選、車庫走行圖、外部入口、主題商店、今日氛圍

第五本第三梯七班合在一版：新頁「候車室」收還沒決定要做的事；路線圖多了看板和篩選；車庫的走行圖通車；桌面小窗、手機小工具、`nextstop://` 連結和 NFC 貼紙讓你不開 App 也能到着、発車；四套主題回到商店；今日頁背景多一層慢慢動的天象；「清空」之後回到剛裝好的樣子。桌機與手機同一版。

**這版兩台要一起升級。** 這一版有兩支資料庫升級（0019、0020）：還沒升級的那台收到新資料會停在「信号待ち」（不會掉資料），兩台都升到同一版就恢復。另外，清空後放回的預設分類只有新版會種，一新一舊會不對稱，所以請一起升。

## 主人會看到

### 候車室：還沒決定要做，但不想忘的事，先在這裡等車
- **新頁「候車室」**（桌機 `Ctrl+9`；手機從「更多 › 站內」進）：想買的、想做的、想去的、想讀想看的、想學的，先記著，不用急著排進行程。一條一列，列首有一枚種類小章；頂端的種類籤「全部｜買｜做｜去｜讀看｜學」帶件數，篩到某一類時上面會出現「N番線・種類名」。
- **種類（番線）可以自己增刪改名、拖曳排序**；某個種類底下還有願望時刪不掉，會告訴你還有幾件。
- **每個種類可以設「實現時做什麼」**：記一筆帳、開一張票、開一條路線、寫一篇日記、補一段時間。按鈕上就寫那個動作，點了直接開對應的表單、內容幫你填好；做完可以復原，那筆記錄被刪掉的話，願望會回到等候。
- 實現了的事收進摺疊的「實現了」區，也會出現在車庫年鑑的「那年今日」和按月的「實現 N 件」。
- 沒有進度條、沒有提醒；只記發生過的事。
- **售票口的願望清單搬了家**：舊資料原封不動全部在候車室的「買」底下；售票口回到四個分頁（清單｜月曆｜統計｜帳戶，鍵 1–4）。
- **側欄第三排改叫「站內」**：運行報告、車庫、候車室三格；手機「更多」最上面那一段同名。

### 路線圖多了看板和篩選
- **看板**：路線頁頁首下多一列「大綱｜看板」（鍵 1／2）。可以照狀態、列車或車站分欄，拖一下就換欄——換欄就是改狀態、蓋済、換列車或換車站，每次都能復原。定期券拖到「済」只済這一班，卡上寫下一班幾月幾號。手機一次顯示一欄，長按拿起卡片時，底部會升起一排落點。
- **車票可以掛車站**：車票詳情和多選工具列多一個「車站」，代表「到這一站之前要做的」。車站被刪、或票搬到別條路線時，票會回到「還沒排站」，資料不會被改掉。
- **篩選清單**：路線一覽多了「路線｜篩選」，可以照路線、荷札、締切、狀態、誤點、優先高組合篩；結果可以看成清單或跨路線的看板，也能排序。路線卡上的「誤點 N」點了直接篩出來。
- **常用篩選**：把目前的條件存起來，之後一點就套用；能改名、更新、排序、刪除（可復原），兩台共用。桌機側欄書封「我的路線」底下會多一段「常用篩選」。

### 車庫的走行圖通車了
所有幹線和路線畫成一張私鐵路網圖：跑完的是實線、停在終點雙圈，還在跑的是虛線，到過的車站是白點。點一條路線就打開它的乘車記錄簿。手機改成直立排，上下捲就看完。路線多了可以點幹線名牌收起來，也能一鍵全部收合、先看全貌（收了哪些只記在這台）。圖上不比大小：線的長短跟済章數、車站數、天數都沒關係。

### 外部入口：不開 App 也能到着、発車
- **桌面小窗**（桌機）：一張小票根，寫著正在跑的班次和「今日還有幾張」，可以直接到着、換車；能拖到螢幕角落、貼齊邊緣、置頂，不會搶走你正在用的視窗。從系統匣右鍵「桌面小窗」或設定〈捷徑與小工具〉打開。
- **主畫面小工具**（手機）：4×1，拉高成 4×2 多出発車格；App 沒開也能到着、発車。從設定〈捷徑與小工具〉（手機在「更多」）加到主畫面。
- **`nextstop://` 連結**：可以開票、開今日、発車、到着。票的 ⋯ 有「複製連結」，設定頁也有発車、到着、今日的連結。連結超過 10 分鐘就不會執行，免得舊連結蓋掉後來的班。
- **NFC 貼紙**（手機）：在設定裡寫入，碰一下就発車，震一下、跳一句提示，不用開 App；同一類再碰＝到着，碰另一類＝換車。桌機沒有 NFC，改用連結。
- **桌機提醒的通知改走連結**：點通知由系統開連結回到 App，希望進了 Windows 通知中心的舊通知也能點回來（見下面〈這一版的邊界〉）。
- **分享文字到私鐵手帳**：App 被系統收掉重建後，不會再把同一段文字重收一次。

### 主題商店：四套主題回來了
- 設定〈一般〉的主題三選旁多一顆「商店」（手機在「更多」的主題下面）：**旅の手帖、少女手帳、夜行寝台、月白**四套，點一張卡就換上，回粉彩星空、銀河鐵道或跟隨系統都在上一頁。換上商店主題後，窗口標題列也會跟著亮暗。
- **手寫字型「辰宇落雁體」**：選了才下載（約 9.5 MB，需要網路），之後離線也能用；手寫的地方（筆記足跡、日曆註記、書封主題名）會換字。字型沒有的假名等字會自動用原本的字補上。
- 主題只存在這台，兩台各選各的。

### 今日頁多一層會動的天象
- 今日頁背景（兩端）：列車走在底部的地平線上，粉彩的天空是候鳥和流星輪流，銀河是流星；天色會跟著當地時間從晨到昏慢慢變。
- 設定〈一般〉和手機「更多」多一區「今日氛圍」：一直有／蓋章時／關閉，淡／中，以及列車、候鳥、流星、晨昏各自的開關。預設是「一直有・淡」。「蓋章時」模式是蓋一枚來一班短車，全部蓋完來一班長車。
- **沒在看就停**：視窗縮小、縮到系統匣、螢幕保護、鎖屏時全部動畫暫停；切到別的程式滿 1 分鐘、或 5 分鐘沒碰，裝飾層也會停。星星在手機上恆亮不閃、桌機低頻閃，今日頁的耗電比一開始少很多。

### 清空之後回到剛裝好的樣子
- 以前「所有裝置一起重新開始」之後，幹線、路線、售票口的分類都不見了，只有時刻表的分類還在。現在統一了：**清空＝回到第一次裝好 App**，每一頁都有幾個常用的預設分類。
- 路線圖有「工作、學習、生活」三條幹線，售票口有支出（飲食、交通、居住、日用、購物、娛樂、醫療、學習）和收入（薪資、獎金、投資、兼職）的預設分類；路線、帳戶、荷札不放。預設可以改名、封存或刪除。
- 只有在一列都沒有時才會種，所以**已有資料的人不會多出東西**，刪掉的預設也不會再回來。別台按「一起清空」後，這台不用重開 App，最晚約 10 秒預設就會出現。
- 舊資料留下的記憶（例如最近用過的荷札、提醒的紀錄）清空時也一併清掉；主題、快捷鍵這些偏好不動。
- 改過名的預設分類，加入同步時會算成你的資料，不會被當成空的蓋掉。

### 修正
- **今日頁開著時不再悄悄吃電**：時刻表徽章的光圈和「運行中」的呼吸點，改成剛出現時呼吸三下就停、之後留靜態標記——以前的呼吸動畫在高更新率螢幕上會一直整片重畫，手機實測佔掉快兩顆核心。配合上面的星星調整，今日頁醒著的耗電大幅下降。
- **推遲後按「復原」，票回到原本的位置**：以前復原只把日期改回來，票會掉到今天清單的最後；清除執行日、批次改期的復原也一樣修了（批次改期反悔後不再留下多餘的繰越章）。
- 路線看板的選取列蓋済，不再把定期券的下一班也蓋掉（大綱也受惠）。

## 底下換了什麼
- **2 個 migration**：0019（候車室的種類表 `wr_kinds`，願望表多 `kind_id`／`target_kind`／`target_id` 三欄；既有願望自動掛在「買」，一筆不搬）、0020（車票多 `station_id`，記掛哪個車站）。
- 常用篩選存成同步設定的一格；主題、字型、今日氛圍、看板與篩選的版面、走行圖的收合都存在這台、不進同步。
- 桌機：新增桌面小窗（獨立視窗）、`nextstop://` 連結（開機時寫入使用者登錄）、提醒通知走連結、監看視窗是否被藏起來的後端（`motion_watch`）、標題列跟 App 亮暗（新增一項視窗權限）。Android：小工具、NFC、連結入口和分享中繼頁（Kotlin）。
- 字型檔下載後存在 WebView 自己的儲存裡，是可以重新下載的快取，不進同步與備份。

## 這一版的邊界
- **手機各項在模擬器上走過，還沒在你的手機上親手點完**：主畫面小工具（HyperOS 是否支援「加到主畫面」、換日顯示）、真的寫一張 NFC 貼紙再碰、字型在手機上下載與離線重開、看板長按拖曳的手感、今日氛圍在手機切背景與關螢幕時是否真的停、手機上的耗電。請上機後先看這幾處。
- **桌機點提醒通知回 App**：通知還在螢幕上時一直都行；這版改走連結後，進了通知中心再點、App 結束後再點，是否都能回來，還沒真點確認。退路沒變：提醒頁底的「最近的提醒」一樣到得了。
- **桌機從瀏覽器真的點 `nextstop://`**、桌面小窗用真滑鼠拖曳與貼齊、系統匣右鍵「桌面小窗」，沒有用手點過。用 ✕ 收主視窗時，前景偶爾會落在小窗上（點別處就回去，無害）。
- 今日氛圍：量的是開發版，正式版的耗電可能不同；星星改低頻之後有沒有看得出的不順、真的螢幕保護與鎖屏的偵測、批次改期的復原，還沒親眼確認。
- 商店主題在手機狀態列的圖示深淺目前仍跟系統，看不清楚再改。
- 看板在 Android 的長按與系統右鍵選單的互動、桌機側板開著時欄區橫捲，留待你上手時看。
- 願望匯出：記錄被刪、願望回到等候後，`願望.csv` 的「實現時刻」仍照印舊時間（從 v1.24 起的既有行為，候車室讓更多動作碰得到）。
- 兩台同時各存一條常用篩選時，以後存的為準，另一條要重存（幾秒的事）。
- 仍需自己的 Cloudflare R2（自用階段）。
