## v1.8.0 · 時刻表①b①c 編輯補完＋通知操作

時刻表的第二、三班車一起進站。**手機不開 App 也能換車**：通知欄常駐一排常用分類，點一格就換、點「到着」就停；電腦的系統匣右鍵也能直接到站、換車。編輯這邊補齊了時間日誌那一套：一塊一次切成好幾段、與上下一塊合併、給這一班一個預估。全 App 的側欄與手機 tab 上，也看得到現在跑的是哪一班。桌機與手機同一版、功能對等。這一版**沒有新的資料庫 migration**。

### 主人會看到
- **手機通知欄就是換車台**：
  - 常駐通知收合時是一排五格常用分類，正在跑的那格亮著、旁邊小字跳秒；點一格就換車，不會打開 App。
  - 下拉展開多一列運行中那一班：分類、「HH:MM 発・預估 1h」、跳秒、「到着」鈕。
  - 停車中通知照樣留著，格子直接発車。
  - 格子預設放最近用過的分類，可以在「分類與設定 › 通知」釘選最多五個。
  - App 被系統關掉時在通知上按的也不會掉：下次打開 App 會照按下那一刻補進軸上。
  - 通知被滑掉會自己回來；手機重開機、第一次解鎖後也會自己回來。
- **鎖屏跟著手機的設定走**：「顯示全部」時鎖屏看得到分類格；「隱藏敏感內容」時只寫「時刻表・運行中／停車中」。通知不響、不震、不跳橫幅。
- **跑太久的提醒準時了**：手機改用精準鬧鐘，門檻一到就響（實測晚不到 1 秒），重開機後也會重排。電腦這版也會跳一則 Windows 通知，同一班只跳一次。
- **電腦系統匣右鍵**：最上面一列寫正在跑的那一班和經過多久，下面是「到着」、「換車 ▸」（常用五個＋「全部分類 ▸」）、「開啟 Next Stop」、「結束」；停車中變成「発車 ▸」。滑過圖示的提示也帶經過時間。
- **〈通知〉設定**：「分類與設定」裡多一節，每一種通知各一個開關：運行中顯示（手機通知欄／電腦系統匣）、跑太久提醒、常用分類格，加上釘選。各台自己記、不同步。
- **一塊切成好幾段**：切開面板改成在時間條上點一下加一刀、可以拖、可以「對半」，每一段各選分類，按「切成 N 段」。切正在跑的那班時，最後一段照舊在跑。
- **合併**：改一塊的面板多了「與上一塊合併」「與下一塊合併」。按下去先出一行「合併後：上課 08:40–10:50」，確認了才合；中間的未記錄一起蓋掉。
- **這一班的預估**：發車時可以展開「＋預估」選 30 分到 3 小時，運行列顯示「預估 1h」，隨時能改或清掉。超過預估時運行列轉赭、寫「誤點 +20m」，回到 App 時問「其實到幾點」。
- **分類進階管理**：每個分類的「⋯」裡可以換圓牌字、搬到別的組、封存；封存的不出現在發車台和通知格，舊的時間塊照常顯示，底部「已封存」可以還原。
- **全 App 看得到運行中**：電腦側欄的「時刻表」與手機底部 tab 的時刻表那格，右上角貼一顆運行中分類的小圓牌；跑太久沒確認時外圈轉赭；到站時縮小淡出。
- **電腦頁內快捷鍵補齊**：`←`／`→` 前一天／後一天、`T` 回今天、`R` 改出發時間、`E` 分類與設定、`S` 切開運行中那一班、`F` 補記最近一段未記錄。`?` 卡片照常列出。
- **上一版的三個小毛病修好了**：改「一天的開始時間」後時刻表立刻換到新的今天；從設定頁回來快捷鍵直接能用；「長時間運行」記號只畫在真的還超過門檻的塊上（選了「留白」或「其實在做別的」的不再被標）。
- **手機底部面板不再半透明透字**。

### 底下換了什麼
- **新的 Android 原生 plugin `tt-notice`**：常駐通知、通知上的換車／到着、跑太久提醒都改由它負責。原生那一層只碰通知、鬧鐘和自己的小暫存，**不寫資料庫**：通知上按的動作先存起來，App 回前景時才經同一套寫入路徑落庫（連同步一起），所以兩台的同步規則跟在 App 裡按的一模一樣。
- 手機通知換到新頻道「時刻表・運行中」（舊頻道會自動刪掉，系統設定裡不會出現兩個）；第一次以新版啟動時，會收掉舊版排過的提醒。
- 通知上的發車用確定性的 id，App 被殺、重開後重複套用也只會落一次；如果另一台在那之後已經換過車，通知上那一班只寫到下一班開始為止，不會把另一台較晚的那班吃掉。
- 手機加了精準鬧鐘權限（`USE_EXACT_ALARM`）與開機重建；這是自行安裝的 APK，權限用途就是跑太久提醒。
- 地基多了一個登記式插槽：側欄與手機 tab 的「運行中標記」，之後別條線也能用同樣的方式掛小記號。

### 這一版的邊界
- 從舊版升級後、**第一次打開 App 之前**，如果舊版排的「跑太久」提醒剛好到點，會用舊樣式響一次；打開 App 之後就由新的提醒接手。
- 手機重開機後，要等**第一次解鎖**通知才會回來（Android 的規定：解鎖前 App 讀不到自己的資料）。
- 兩台幾乎同時對同一塊動手、一台「合併」一台「切開」時，留下來的會是切開的那一份，畫面上沒有提示。這跟全 App「編輯勝過刪除」是同一個規則，等那個提示做出來時刻表會一起受惠。資料仍會兩台一致、不會少時間。
- 手機版提示訊息比較長時只顯示一行、後半句會被截斷（全 App 共用的提示元件，之後統一修）。
- 在通知上連續快速點好幾格，會在軸上留下幾秒長的小碎塊（照規則是對的，之後看要不要收起來）。
- Android 返回鍵還是不會先關底部面板，會直接把 App 退到背景。
- 還沒有：任務連動（從車票発車、花費時間自動累積）、統計與環比、日程視圖、荷札接軌、手機桌面小工具。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝
- Android（arm64）：`NextStop_1.8.0_arm64.apk`，可直接覆蓋。第一次打開時系統可能會問通知權限，允許之後通知欄的格子才會出現。
- Windows x64：`NextStop_1.8.0_x64-setup.exe`（NSIS）。
