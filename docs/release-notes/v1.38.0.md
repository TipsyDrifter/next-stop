# v1.38.0 · 售票口深度進化：品項／來源 × 隨筆備註雙欄分離、舊帳分流小幫手、手續費獨立欄、刷卡分期與信用卡帳單週期提醒

這一版替售票口完成了期盼已久的四大升級：將帳目、定期帳與常用票種的單一備註拆為「品項／來源（接管歷史補完與自動帶分類）」與「隨筆備註（純生活感想、不污染詞庫）」黃金雙欄，並附帶多機同步安全的存量無損搬家與「舊帳隨筆分流小幫手」；為支出、轉帳與收入補上「手續費」獨立選填欄，免再拆成兩筆帳；加入支援自動攤提、進度追蹤與三段刪除的「刷卡分期」；並為信用卡帳戶完整建立結帳日、繳款截止日、預設扣款帳戶、本期應繳總額、一鍵繳卡費預填與〈提醒〉到期通知。桌機與手機同一版號。

## 主人會看到

### 帳目「品項／來源 × 隨筆備註」黃金雙欄分離 ＆ 舊帳無損搬家
- **記帳更俐落、補完詞庫不再被長句污染**：
  - 桌機與手機的記帳大票／表單、定期帳與常用票種同步拆出**「品項／來源」**與**「隨筆備註」**兩欄。
  - 「品項／來源」接管歷史補完與自動帶出上次分類；「隨筆備註」純粹留給主觀生活感想（不進入補完詞庫）。帳簿列與搜尋結果以「主字品項 ＋ 柔和淡色隨筆」並列呈現。
  - 搜尋、快速跳轉、一日運行專頁消費明細、CSV 匯出、荷札預覽、失物招領與外部助理皆同步接通雙欄。
- **存量舊帳無損搬移 ＋ 一次性「舊帳隨筆分流小幫手」**：
  - 升級開啟即以多機同步安全的方式，將存量舊帳原備註無損移入「品項／來源」。
  - 管帳面板內新增**「舊帳隨筆分流小幫手」**（雙端可用），自動篩出含括號、分隔符或長句的舊帳，支援勾選、就地微調切分並一鍵套用。

### 手續費獨立選填欄、刷卡分期與信用卡帳單週期提醒
- **轉帳／跨國刷卡「手續費」獨立選填欄**：
  - 支出、轉帳與收入表單皆新增精巧的「手續費」選填欄（以來源帳戶幣別計價，免拆兩筆帳），填寫即時試算實扣／實收金額；帳簿列呈現 `含手續費` 淡色副標（完整尊重金額隱私遮罩），並正確計入帳戶餘額與當月支出統計。
- **刷卡分期（期數設定、自動攤提與進度追蹤）**：
  - 記新支出時可選 `不分期 · 3 · 6 · 12 · 24 期` 或自訂 `2–60 期`，即時預覽首期（含餘數與手續費）與後續每期金額及入帳日，一鍵建立整組各月分期帳（每月只吃當月那一期不爆預算），帳簿列標示素雅細框 `分期 2/6` 徽章。
  - 檢視任一期帳目時呈現**刷卡分期進度卡**（已入帳期數、墨色進度條、剩餘未攤金額與下期日），刪除支援「只刪這一期／刪本期與後續期數／刪除全部分期」並保留 6 秒復原。
- **信用卡結帳日、繳款截止日、本期應繳、一鍵繳卡費 ＆〈提醒〉連動**：
  - 信用卡帳戶（新增或編輯詳情頁）支援設定**每月結帳日（1–28 號）**、**每月繳款截止日（1–28 號）**與**預設扣款帳戶**。
  - 桌機與手機信用卡帳戶卡直接呈現本期帳單、已繳、**本期應繳總額**（或「本期已繳清」）與下期未出帳消費，卡片附**「繳卡費」**快捷鈕一鍵預填轉帳至該卡。
  - 〈提醒〉設定「售票口」分組新增**「信用卡繳款提醒」**開關與提前天數（`1 / 3 / 5 / 7 天`），繳清後自動靜音，點擊通知直達該信用卡帳戶。
