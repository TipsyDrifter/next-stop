## v1.4.0 · 時刻表①a 計時・發車台・軸＋系統匣

側欄第二排的「時刻表」通車了。這一版是時間記錄的第一班車：按一下分類就「発車」開始計時，再按另一個就「換車」，軸上一天的時間一塊一塊接起來；沒記到的空白可以事後補。桌機多了系統匣——App 不開著也看得到現在在跑什麼，按 ✕ 不再是關掉而是縮進去。桌機與手機同一版、功能對等。這一版有新的資料庫 migration（0006），升級時照舊先備份再升級、舊資料不動。

### 主人會看到
- **時刻表頁**：桌機側欄下排「時刻表」不再反灰，`Ctrl+5` 直達；手機底部 tab「時刻表」亮起。桌機兩欄（左發車台、右軸），`V` 切軸全寬；手機頂端「發車台｜軸」切換，運行列固定在頁面與 tab bar 之間。
- **發車・換車・到站**：發車台三組（本務／生活／休閒）十六個分類格。點一格就発車，運行列開始跳秒；再點另一格＝換車，前一班自動到站、軸上兩塊首尾相接。到站 toast 十秒內可撤回。「換車——接下來做什麼？」可以選「10 分前」補回切換的延遲。點運行列上的出發時間可以改。
- **軸上補記與修改**：點一段「未記錄」補記（選分類、±5 分調起訖、「接上一塊」）；點已有的塊改分類、起訖、刪除（可撤回）、切開。改到會蓋住別塊時先告訴你會蓋掉幾塊、切短幾塊。
- **分類與設定**：發車台右上「編輯」新增分類、改名、換色（八色）、設預設長度、排序。換主題時分類色跟著換成那個主題的一組。
- **跑太久與回來時主動問**：一班跑超過門檻後回到 App，一進頁就問「○○已經跑了 9h…其實到幾點？」；略過不答運行列整列變赭色提醒。App 關掉再開，秒數接著算、不從 0 開始。
- **跨日**：翻到昨天看昨天的塊；跨過日界線的塊兩天各顯示一段、標「續」。剛過日界線一小時內編成條上有「昨日 ›」。軸頂端有本日已記錄／未記錄、今日各分類合計、本週三組合計。
- **不開 App 也看得到運行中**：
  - 桌機：系統匣有 Next Stop 圖示，發車時右下多一顆紅點、滑過顯示「分類・HH:MM 発」。
  - 手機：通知欄常駐一則「分類・HH:MM 発」，到站消失；被滑掉回到 App 會自己貼回來。
  - 兩邊都能在設定頁關掉「顯示運行中」。
- **桌機視窗行為改了**：**按 ✕ 改成縮到系統匣，計時照跑；從系統匣右鍵「結束」才真的關；手機不受影響。** 左鍵點圖示視窗回來。App 藏在系統匣時從開始選單再開一次不會多開一個，原本的視窗跳出來。
- **日界線預設改 06:00**（只影響新裝機與重新開始；已裝機的照自己設定頁的值）。設定頁日界線設成 0 點不再被吃成預設。
- **手機時刻表頁上，旅客筆記的「記一句」浮動鈕不再蓋住運行列的「発車／到着」**。

### 底下換了什麼
- **新同步表 `time_blocks`、`time_categories`**（migration 0006）：時間塊與分類跟著既有的端對端加密同步往返。十六個起手分類由 App 自己種（經 repository、進 oplog），不由 migration 種，所以兩台不會出現兩份；主人自建的分類才算進「這台有沒有資料」。
- **同步整理規則**：兩台同時記、其中一台離線記了幾段，整理時看「誰較晚發車」而不是整列最後寫入，離線那台的塊不會被另一台一直開著沒人管的那班整段蓋掉；整理只掃最近 62 天，10k 筆從 1.6 秒降到 15 毫秒。
- **桌機殼層**：系統匣圖示、單一執行個體（以 identifier 為鍵，沙盒與 dev 互不擋）、✕ 縮匣；「結束」走正常關閉流程。
- **手機**：常駐通知走系統通知（`ongoing`），不是前景服務；加了 `POST_NOTIFICATIONS` 等權限。
- 浮動鈕避讓改成通用約定：各線手機頁自己宣告底部列高（CSS 變數），旅客筆記的鈕照著讓。

### 這一版的邊界
- 手機的「跑太久」背景提醒用系統的不精準鬧鐘，可能比門檻**晚最多一小時**才響。App 開著時提醒是準的。
- 手機底部面板（分類與設定）背景半透明，後面的字會透出來；下一版修。
- Android 返回鍵不會關底部面板，會直接把 App 退到背景；之後處理。
- 改日界線後「今天」要重讀才會換；從設定頁回來要先點一下畫面快捷鍵才會動。這兩件排下一個車次。
- 還沒有：日程視圖（預定對實績）、任務側板的花費時間、標籤軌、到站／換車的通知動作、桌機開機自動啟動。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝
- Android（arm64）：`NextStop_1.4.0_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.4.0_x64-setup.exe`（NSIS）。
