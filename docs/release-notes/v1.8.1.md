## v1.8.1 · 售票口匯入對帳修正

一班小修。主角是「從財務管家匯入」：上一版說好先停在預覽、不要按匯入，那筆對不上的落差查清楚了，也修好了，**這一版起可以正式把財務管家的舊帳搬進來**。另外帶上兩個手機的小修。桌機與手機同一版。這一版**沒有新的資料庫 migration**。

### 主人會看到
- **匯入的餘額對得上了**：在帳戶上記的美金、人民幣帳（例如訂閱服務），以前會被多換一次匯率、放大約三十倍，「帳戶」那顆帳戶的餘額因此差了一大截。現在照財務管家記的台幣金額入帳，原幣金額也照實記成 `USD`／`CNY`。
- **預覽卡抄餘額就能自動對帳**：照財務管家帳戶頁抄下各帳戶目前的餘額，預覽卡會判斷「差別」該加還是減，全部對上會顯示 ✓。
- **手機提示訊息可以換行**：比較長的提示最多顯示兩行，不再被截斷。
- **手機捕捉鈕只在「今日」子頁抬高**：切到行程表子頁時，捕捉鈕回到原位，不會懸在半空。

### 底下換了什麼
- 讀財務管家備份時多讀一個欄位（交易幣別的原始金額）；查清楚的讀法是：備份裡的主要金額本來就是帳戶幣別，原始外幣另外存。舊的讀法把它當原幣再換一次匯率。
- 地基小修：路線、支線側板多了別條線可以掛欄位的位置；快速跳轉每條線可以登記好幾組結果；同步拉完之後會通知各線（這一版都還沒有線在用，畫面不變）。

### 這一版的邊界
- **匯入建議只在一台做**（桌機），手機靠同步拿到；兩台各自匯入、而且其中一台事先手建了同名帳戶時，帳戶會被拆成兩個。
- 外幣**轉帳**（例如從美金帳戶轉到台幣帳戶）沒有樣本可驗證，匯入時仍照舊算法；主人的備份裡沒有這種帳。
- 手機捕捉框「記一筆」票根的提示字比框寬一點點；售票口下一班（看帳）修。
- 手機匯入預覽卡上檔名那一行會顯示一串數字（系統給的文件編號），不影響匯入；之後修。
- 手機捕捉框存檔失敗時，提示會被重新彈起的鍵盤蓋住，收起鍵盤才看得到；之後修。
- 還沒有：收支統計與報表、日曆、搜尋（售票口②）；預算與管帳（售票口③）。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝

- Windows x64：`NextStop_1.8.1_x64-setup.exe`（NSIS）。
