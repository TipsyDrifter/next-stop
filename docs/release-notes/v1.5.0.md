## v1.5.0 · 售票口① 帳本

側欄與手機 tab 的第五格「售票口」通車了。這一版是記帳的第一班車：一本照月份翻頁的帳簿、快速記一筆的小票與攤開的大票、多帳戶與多幣別、以及把財務管家的備份整本搬進來的匯入功能。桌機與手機同一版、功能對等。這一版有新的資料庫 migration（0007），升級時照舊先備份再升級、舊資料不動。

### 主人會看到
- **售票口頁**：桌機側欄下排「售票口」不再反灰，`Ctrl+6` 直達；手機底部 tab 改成五格、售票口佔第五格，「更多」搬到每頁右上角的「⋯」。
- **帳簿**：照月份翻頁（‹ ›），一天一組；書封換成「帳戶 ACCOUNTS」——資產／負債／合計小卡跟著帳戶清單一起捲。
- **記一筆**：`N`（手機「＋」）開表單；支出、收入、轉帳三種。收入的大票右上蓋朱「領収」章、轉帳是墨「振替」；手機表單一屏放得下，鍵盤彈出收起都不擠。
- **帳戶**：新增帳戶選群組（現金、銀行…）、幣別、期初餘額（填了會自動記一筆「精算」）；「調整餘額」直接把帳戶調到目標數字。
- **多幣別**：「幣別與匯率」管理；在 TWD 帳戶記一筆外幣會同時顯示原幣與折算（例如 `10 USD ≈ NT$ 316`）。
- **分類**：分類管理可加子分類；封存的分類表單選不到、舊帳照樣顯示。
- **捕捉框直達**：`Ctrl+N`（手機捕捉鈕）的票根多了「記一筆」，打 `80 午餐 @現金` 一行完成記帳，toast 可復原。
- **從財務管家匯入**：管理 → 從財務管家匯入（`.mmbak`）→ 先看預覽卡（幾個帳戶、幾個分類、幾筆交易）再決定；匯入後可重匯，只補新增與修改過的，不會重複。
- **刪一筆 10 秒內可復原**；兩台之間帳戶、分類、每一筆、餘額照常端對端加密同步。

### 底下換了什麼
- **四張新同步表**（migration `0007_ticket_ledger`）：幣別、帳戶、分類、帳目，全部走既有的端對端加密同步；金額一律以「分」存整數，折算另存，不會有小數漂移。
- 書封頁務件改走共用插槽（各線都能放自己的頁務件）；手機殼的五格 tab 與「⋯」鈕是全 App 的小改版。
- 匯入是增量式：以財務管家的修改時間判斷新增／修改／略過，重匯安全。

### 這一版的邊界
- **匯入建議先停在「預覽」**：「帳戶」這顆帳戶的餘額與財務管家顯示值有一筆待查的落差，下一班（看帳）會把對帳規則查清修好——在那之前選檔看完預覽卡按取消就好，先不要按「匯入」。
- 手機捕捉框「記一筆」票根的提示字比框寬一點點；下一班修。
- 上一顆測試版裡的「行程表」（多日行程）不在這一版——它搭下一班 v1.6.0 出爐。
- 還沒有：收支統計與報表（售票口②）、預算與管帳（售票口③）。
- 仍需自己的 Cloudflare R2（自用階段）。

### 安裝
- Android（arm64）：`NextStop_1.5.0_arm64.apk`，可直接覆蓋。
- Windows x64：`NextStop_1.5.0_x64-setup.exe`（NSIS）。
