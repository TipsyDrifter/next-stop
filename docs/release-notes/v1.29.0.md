# v1.29.0 · 時段排程大一統（單日｜週時段）、臨時班次預留時段、跨層級時間目標、滑鼠側鍵瀏覽歷史與側欄群組收合

這一版將小時級排程統一收進「**時刻表 › 日程**」，新增「**單日 ｜ 週時段**」切換，同時讓「行程表」專心負責日期尺度（月｜週｜串流）並附上一鍵「**排時段 ›**」跳轉；在日程排時間時，還沒拆細成車票的主題可以直接建立虛線車廂邊框的「**臨時班次**」先佔時段，事後直接発車計時或一鍵轉為正式車票；時刻表的「**時間目標**」全面打通「分類 ∪ 路線／支線 ∪ 車票／列車／車廂 ∪ #荷札」跨層級自由聯集與母層級自動向上匯總；桌機並補上對齊手機返回鍵層級的**滑鼠側鍵／快捷鍵上下一頁導航**與**側邊欄群組標題點擊收合**。桌機與手機同一版。

## 主人會看到

### 時段排程大一統：「時刻表 › 日程」支援「單日 ｜ 週時段」
- **小時級排程統一歸位**：退役過去分散在「行程表 › 時段」的獨立小時軸，讓「**行程表**」專注於「哪一天（桌機：月｜週｜串流；手機：清單）」，並在行程表頁首、日曆格預覽彈窗、串流日標題與手機週條附上「**排時段 ›**」按鈕，一鍵跳入「時刻表 › 日程」對應日期。
- **單日（預定 vs 實績）｜ 週時段（手機為三日時段）自由切換**：
  - 在「時刻表 › 日程」可隨時切換「**單日**」與「**週時段**」（手機為「**三日時段**」）。
  - 週時段頂部常駐跨日「**還沒排時刻**」待排池，可點選或拖曳車票直接排入一週內任意一天與小時格；格內卡片支援跨時段、跨日拖曳改期，點擊日欄頭可立即切回該日「單日（預定 vs 實績）」檢視。

### 不綁車票的「臨時班次／主題預留時段」
- **不必先開假車票就能預留時段**：排日程時若只想先留一段主題時間（例如「週四下午讀日文」、「專題衝刺」），可直接點「**＋ 臨時班次**」或在預定欄／週時段格空白處雙擊建立，畫面以**虛線車廂邊框**與「`臨時`」徽章區隔。
- **直接発車計時、自動實績對照、或事後轉正式車票**：
  - 臨時班次可選填綁定「路線／支線」與「時間分類」。
  - 點開面板可按「**▶ 発車（開始計時）**」直接啟動計時（自動帶入綁定的路線／支線、分類與主題備註），或按「**轉為正式車票**」在目標路線／支線下一鍵生成帶好日期、時刻與預估時長的正式車票。
  - 尚未轉為正式車票前，只要當天有相同「路線／支線」（含底下子孫節點）或相同「時間分類」的實績時間塊，就會自動配對納入「預定 vs 實績」對照。

### 跨層級時間目標（分類 ∪ 路線／支線 ∪ 車票／列車 ∪ #荷札）與支線關聯
- **時間塊可直接綁定「支線」**：発車、補記與時間塊編輯面板的任務關聯選擇器，現在除了車票、列車、車廂外，也能直接選取「**支線**」。
- **四維度自由聯集（OR）＋ 母層級自動向上匯總**：
  - 新增或編輯時間目標時，可同時勾選「**時間分類**」、「**路線／支線**」、「**車票／列車／車廂**」與「**#荷札**」。
  - 多個條件之間採**聯集（OR）**計算——同一個時間塊若同時命中多個條件（例如既屬於「學習」分類、又掛在「日文支線」下）只會計算一次，絕不重複灌水。
  - 當目標勾選了某條「路線」或「支線」（或「列車／車廂」）時，掛在它底下所有子孫節點的時間塊都會自動向上匯總計入。

### 滑鼠側鍵／鍵盤「上一頁・下一頁」（對齊手機返回鍵層級）
- **支援滑鼠側鍵（返回／前進）與鍵盤 `Alt+[` / `Alt+]`（及 `Alt+←` / `Alt+→`）**：
  - **四層直覺優先序**：① 先收起眼前的臨時選單、右鍵選單、日曆預覽卡、推遲選單、小算盤、確認框或靈感捕捉框 → ② 在彈出視窗（設定、分類與設定四籤、售票口管理視窗、快速跳轉、快捷鍵指引、右側記帳面板）內切回上一籤／退回母清單／關閉視窗（按下一頁可重新打開）→ ③ 退回分頁內下鑽（支線聚焦、常用篩選、選中筆記、路線篩選、日記日期、荷札下鑽、時刻表與售票口子視圖、統計分類下鑽、車庫記錄簿）→ ④ 跨分頁往返。
  - **手動關窗智慧收捲**：手動點右上角 `×` 或按 `Esc` 關閉彈出視窗時，歷史游標會自動退回開窗前的位置，之後按返回鍵不會把剛關掉的視窗又彈出來。

### 點擊側邊欄群組標題收合／展開
- 左側深色書封側邊欄的群組標題（各條**幹線**、路線圖**常用篩選**、時刻表**分類群組**、售票口**帳戶群組**、旅客筆記**篩選與荷札目錄**）現在皆可點擊收合／展開，並各自記住收合狀態。
