## Default Permission

時刻表通知（Android）：貼／收常駐通知、取與確認待處理動作、排與取消跑太久提醒、查狀態、事件監聽；旅客筆記：取與確認分享進來的文字；截止提醒：交清單、取已響與點開的落點；外部入口：取與確認連結、小工具、寫 NFC 貼紙

#### This default permission set includes the following:

- `allow-take-shared`
- `allow-ack-shared`
- `allow-post`
- `allow-remove`
- `allow-take-pending`
- `allow-ack-pending`
- `allow-schedule-reminder`
- `allow-cancel-reminder`
- `allow-status`
- `allow-rem-sync`
- `allow-rem-take-launch`
- `allow-register-listener`
- `allow-remove-listener`
- `allow-ext-take`
- `allow-ext-ack`
- `allow-widget-sync`
- `allow-widget-status`
- `allow-widget-pin`
- `allow-nfc-status`
- `allow-nfc-write`
- `allow-nfc-cancel`
- `allow-nfc-open-settings`
